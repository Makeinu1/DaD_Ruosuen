# 第一話 全体レビュー v0.1（2026-11-26）
> DM専用・作者確認前の監査と改善提案。Notion Agent Operating Guide v0.0.9と桜井式Skillsの非公式要約を参照。PR #56の現行資料を対象とする。確定済みの物語・世界設定・数値を変更しない。机上レビューであり、実卓・実PCデータ・最終映像・実地形は未検証。

## 1. 総評
導入から終幕まで骨格は成立。ルオスエンを「自由に生き、自由に冒険する」「仲間とともにまだ知らない世界を見つけに行く」場所として体験させ、「来年もみんなで一緒に冒険しよう」へつなぐ。新規イベントは原則増やさない。最大の弱点は、映像/物語の完成度に比べ、街道と洞窟の攻略・実利・地図操作がまだ抽象的なこと。第一話の価値は映画だけではなく、プレイヤーがそこへ自分の判断でたどり着くこと。

## 2. 時間配分案（実時間・4人Lv2・一回完結の目標）
| 場面 | 基準分 | 遊びと進捗の目印 |
|---|---:|---|
| 導入・受注 | 15 | ベルとタッカー、仕事を選ぶ、目的が明確 |
| 街での準備 | 20 | 地図・装備・手掛かり、目的に応じた準備 |
| 地下街道 | 20 | HOME/GATE、地図で分岐確認、D100三回 |
| 固定洞窟 | 50 | 痕跡→経路選択→戦闘/地形攻略→湖への道 |
| 地底湖 | 25 | 一輪→蕾→観察・推理→開花→採集 |
| 鯨・上映 | 7 | 20秒即応、行動処理、70.5秒上映 |
| 帰路・ベル再会 | 6 | 静寂・持ち帰る成果・安全な復路短縮 |
| 元冒険者・カード | 8 | 花便り・伝承・手渡し |
| 精算 | 4 | 合意済み成果・GP・記録、タッカー演技なし |
| 休憩 | 10 | 湖到着前など自然な区切り |
| 合計 | 165 | 3時間枠なら予備15分、3.5時間枠なら45分、4時間枠なら75分 |

開催時間は未決（repo READMEの3〜4時間×1〜2回想定を変更しない）。3.5時間枠を一回完結の目安として提案。短時間ルートは戦闘回避や準備短縮により120〜140分程度、通常165分、深いRP/寄り道/戦闘/妨害の多い場合210分超もあり得る。実測なし。残り時間を満たすために戦闘やイベントを増やさない。残り45分を目安に湖以降の時間を確保できるかDMが確認し、必要ならPLと休憩/次回の区切りを相談（世界内の強制タイマーではない）。

## 3. 桜井式の場面別評価と改善
| 場面 | 評価 | 具体的改善 |
|---|---|---|
| 受注 | 人情と実利の異なる動機がよい | 世界説明から始めない。ベルの困り事→タッカーの追加仕事→プレイヤーの質問。地図院の創設史等は聞かれた時だけ |
| 準備 | 選択の自由はあるがNPC巡回の恐れ | 行き方に必要な最低情報を受注/地図で確保できるように。地図院・塔・店は任意。買う/借りる/既存の情報を使う等、必須の回り道を作らない。実物の携行図で道標の使い方を教える |
| 街道 | 54項目・3ロールの枠組みはよいが「観察するか通過」だけが多い | 目の前の具体的な機会と小さなリターンを足す（道の情報・助け合い・素材等）。一言描写の平穏は残す。3区間で文明から未整備の境目を体感。通常は1〜3分/件。種類・数・戦闘データ・価値は未決 |
| 洞窟 | 最優先。Aはクモのいる近道、Bは安全策で通れる岩棚。時間が主要コストでないのでAが弱い | 距離・地形・リスク・利益を具体化。Aは旧道現況と短い帰路/情報、Bは資源温存と迂回路情報。安全な工夫は成功にするが、どちらも選ぶ理由があるように。報酬は戦闘だけに結びつけない。戦闘なら糸・遮蔽・救助で4人の行動に意味を出す。クモ1体は試案でHP/ダメージ等を実PCで確認。任意鉱物横穴は主筋に必要ない |
| 湖 | シナリオの探索面の強み | 一輪しかない→観察で蕾→同じ地点に二輪目→推理→実際に開く。判定は予測・知識を補助。PCが早く解けばそのまま進める、全失敗でも自然現象で進む。絶対時刻と地形・早着/遅着を検証 |
| 鯨 | 20秒の緊張と通過の解放、映画の報酬が成立 | 一度だけ即応、通常は余計なロールなし。妨害も処理。採用A/B/C/D接続で全編の上映機会、PCの結果は別。過去映像は通常より感動が弱いという限界を認める |
| 帰還 | 短い復路とベルのみの再会が適切 | 既知安全路の再ロールなし。未解決危険のみ処理。プレイヤーの成果整理を簡潔に |
| 終幕 | 花便りと実物カードでテーマ回収 | 説明でなく花を受け取る反応と会話。伝承は短く、将来の約束を強制しない。カードの余りなし対応・精算方法を決める。物語上の最後の台詞をカードの手渡しに置き、精算を事務処理として分離する提案 |

## 4. 全編の緩急
導入の好奇心→準備の見通し→街道の小さな発見→洞窟の判断/緊張→湖の解放→花が足りない違和感→推理の達成→鯨の急な緊張→通過/映画の驚異→静寂→人情の報酬。難易度や戦闘の連続で盛り上げない。最大の視覚的報酬は鯨、最大の物理的記念品はカード、プレイの達成感の山は洞窟と湖。報酬は小さな進展（分岐を理解、地図開示、通過、花発見）をその場で返す。

## 5. リスクと未決事項（実装優先度）
P0：卓で成立するために必要
- 受注・情報源・携行図の具体的な案内。「地図の通りに進む」ではなくR3/R65/S34入口をPCが選び、どこから未整備か理解できる。街道表はS33/S34未決とあるが洞窟稿はS34候補に絞っているため、確定時に統一。
- 洞窟探索図・戦闘図、入口/分岐/通路幅/高低差/遮蔽/足場、A/Bの意味ある差、クモの数とデータ、リターンの実価値、失敗と帰還条件。実PCシートは非公開で個別確認、公共repoに書かない。
- 地底湖の探索地図と世界時刻（開花A/B/C、鯨W）。標準到着だけでなく早着・遅着・寄り道・短休憩で変わること。採集終了に同期させる演出は標準ケースであり、PCの行動で自然法則を変えない。
- 報酬と費用の確定。現行候補はパーティー合計で花10、経路10〜20、群生20〜40、鯨50〜100GP。全成果で90〜170GP、4人なら一人22.5〜42.5GP（税・旅費等の控除前）。会員20GP・HOME費用・地図購入等との比較、非会員/任意参加/部分達成/売買拒否を定義。鯨を見ないことは依頼失敗ではない。
- DMの一枚早見表（各場面の入口/出口/手掛かり/裁定/時間/投影キュー）とゲーム内時計/報酬チェック欄。既存詳細資料への参照と整合し、正本の重複を増やさない。
P1：演出と使いやすさ
- 鯨の接近距離・実PC呪文・特殊裁定、上映中断とA/B/C/D運用、現行v14.9bとの照合（README冒頭の旧v12参照は最新絵コンテ入口と整理要）。
- 最低限の投影素材、湖A/Bの同じ場所の見え方、地図開示素材、既存映画の再生テスト。
- 元冒険者の人物像・台詞・カード枚数/花不足/手渡し。必要なカード実物を準備。
P2：後回し
- 全NPCのフルアニメ、街全域の新規原画、全遭遇の固有名/専用イラスト、地図院の全手続きの演技、鯨の詳細生態/CR/戦闘能力、幸運の将来の具体的回収（今回の裁定に必要な部分は除く）。

## 6. 全体机上ケース
| ケース | 進行 | 確認事項 |
|---|---|---|
| 慎重・短い | 受注→最低限準備→街道通過→B安全策→推理成功→静観→帰還 | 短くても達成を認める。追加戦闘で引き延ばさない |
| 通常 | 準備・地図→3遭遇→A戦闘またはB攻略→花の調査→20秒即応→通常映画→カード | 165分を基準、45分余裕の枠案 |
| 全技能失敗 | 道の基礎情報は与える→地形で別方法→月光で開花→採集 | 必須成功なし。ただし実際の危険/資源消費は残る |
| 寄り道・戦闘多め | 街/街道/横穴で長く遊ぶ→遅着→実際の湖の状態 | 時間超過はPLと相談、イベント追加なし。時刻を巻き戻さない |
| 鯨に干渉・早退 | 実効果→A/B/C/D適用→実際の成果のみ精算 | 上映機会は保証、体験の強制・虚偽の目撃なし |
| 未達・花の余りなし | ベルの反応・部分精算→訪問希望時のみ→カード代替は未決 | 成功の偽装をしない。次回に続けてもよい |

## 7. 結論と推奨作業順
骨格の拡張を止める。まず洞窟攻略と詳細地図を作る（A/Bのリターン、実戦闘、手触り）→湖の物理配置と時刻→報酬額/費用と精算→DM早見・投影・カード→全編テスト。初DM/初心者想定で、実際に何を見て何を選べるか、判定成功/失敗時の返答、時間を測る。映画は既存制作の範囲を維持。これらは監査上の提案で作者承認待ち。既存承認済み方針は変更しない。
