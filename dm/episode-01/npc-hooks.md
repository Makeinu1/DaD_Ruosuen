## 年の瀬のモグラの寝床（2026-11-26作者承認）

**今年最後の依頼が、4人にとって最初の共同冒険になる。**

- 帰省する客、仕事納めの商人、一年の冒険を語る客などで年の瀬を表現する。タッカーは期限を終えた掲示物を外し、年内の掲示受付を終える。ベルは閉鎖間際に駆け込むが間に合わず、途方に暮れる。掲示板が空きつつあるのは年内の仕事が終わりつつあるためで、仕事が一切ないわけではない。
- ベルは個人の願いを拾い上げ、タッカーは異なる職能・立場の人をつないで仕事として成立させる。二人がそれぞれPCに声をかけ、一つのテーブルに集まった4人に同じ依頼を提示する。
- 人情、金銭、商売、探究、好奇心など参加のきっかけを複数用意する。PCの内心や職業別の役割は固定しない。報酬交渉、情報収集、個人的な目的を持つことを認める。
- 短い仕事は直接紹介する既存の仕組みを維持する。掲示板は今後PC自身も買付・情報募集・仲間探し等に活用できる。制度の詳細は既存の[地下の仕事と商館街区](../../world/04_地下の仕事と商館街区.md)に従い、独占や登録義務を追加しない。
- 進行の目安：情景→PCの登場→二人の声かけ→同席して依頼説明→交渉・相談→自由準備。20〜25分は仮の目安。全員が初対面である必要はない。

### 掲示板閉鎖間際のベル（2026-11-26作者指定）

ベルは年内のチクタク掲示板の閉鎖間際に急いで駆け込むが、依頼の掲示に間に合わず途方に暮れる。ベルが元冒険者に約束した仕事ではなく、自分のお節介で採集を頼もうとしている点を維持する。掲示受付の終了は個人間の直接依頼を禁止する制度ではない。

掛け合い例（参考・固定台本ではない）：

- タッカー「さて。今年の仕事も、これでおしまいかな」（掲示物を外して時計を見る）
- ベル「待って、待ってください！ まだ一件あるんです！」（息を切らして駆け込む）
- タッカー「おや、ベル。残念だが、今年はもうおしまいだよ」
- ベル「えっ！？ もうそんな時間ですか！？」（慌てて時計を確認し、片付けられた掲示板を見る）
- ベル「どうしましょう……。今からじゃ、誰にお願いすれば……」
- タッカー「やれやれ。今度は何を引き受けてきたんだい？」
- ベル「引き受けたわけじゃないんですけど……」

DMはここでPCが自分から話しかける機会を設ける。誰も関わらなければタッカーから声をかける。長いNPC同士の会話でPCを待たせず、依頼の説明と追加依頼へ進む。時計の仕草は既存演技ガイドに従う。

| PCの質問・行動 | DM用の参考対応 |
|---|---|
| 何か困っているのか？ | ベル「お仕事をお願いできる方を探していたんですけど、掲示板に間に合わなくて……」 |
| 掲示板が閉まったら仕事を受けられない？ | タッカー「掲示はおしまいだが、直接話をする分には構わないさ」 |
| 掲示板をもう一度開ければ？ | タッカーは掲示の再開を必須とせず、目の前にいる人との直接の商談を提案する。強制的な規則や嘘で拒まない。 |
| ベルに話しかける | 自発的な行動を優先し、依頼説明へ進む。 |
| 誰も話しかけない | タッカーが4人に声をかけ、ベルも事情を説明する。 |

閉鎖の時刻・年末の営業日程・依頼票の現物・具体的な台詞は未確定。掲示板が閉鎖されても街の全ての仕事が終了するわけではない。採集依頼の期限と掲示受付の終了を混同しない。

## タッカーからの追加依頼（2026-11-26作者承認）

ベルが見つけた個人の願いに、タッカーは既存の需要・商機を重ねる。条件整理だけでなく、自ら追加報酬を積み、同じ探索で複数の仕事が成立するように手配する。請負人・依頼者・仲介者に利益が生まれる形を目指す。魚・凧は後続話の候補として保留。二人とも冒険には同行しない。

| 目的 | 成果 | 報酬 |
|---|---|---|
| ベルの主依頼 | 空雪花の生花を採集・持ち帰る | ベルの自腹による基本報酬 |
| タッカーの追加依頼 A | 地底湖への現在の経路を記録・確認する | 追加報酬 |
| タッカーの追加依頼 B | 空雪花の群生地の分布・位置を調べる | 追加報酬 |
| 任意の情報買付 | 珍しい目撃情報・発見を報告する | 情報に応じた対価 |
| PC独自の目的 | 魔石・素材・地理などの自由探索 | 個人的な収穫等 |

追加目的は任意。断る・未達成でも主依頼の成功や基本報酬には影響しない。地理情報は実際の探索成果に基づき、地図院への正式登録・承認は既存の地図運用に従う。探索の負担と追加報酬を釣り合わせ、同じ地形・探索素材を活用する。特定PCや技能判定だけに依存させない。

### 鯨の伏線（採用方針）

タッカーが珍しい情報を買うと伝え、鯨を間接的に匂わせる。出発前に鯨の名称・姿・遭遇の確実性を自分から明示せず、鯨探しや追跡を契約条件にしない。PCが質問したら、タッカーが実際に知る情報の範囲で応答し、不自然な隠蔽はしない。何をどこまで知っているかは未決。帰還時の報告や反応もPCの実際の経験を尊重する。

### DM演技指針：妙な話を質問されたら（2026-11-26・卓用試案）

**核心：隠すのではなく、本人も断片的な噂しか知らない。** DMの知識とタッカーの知識を分離する。以下は演技のための暫定的な知識範囲・参考台詞であり、噂の実際の出所や鯨の生態を新たに確定するものではない。

- タッカーは地底湖付近で何かを見たという断片的な噂を聞いているが、実際には目撃しておらず、正体・危険性・出現条件・時間・鯨との関係を確認できていない、という想定。大きなものが動いたという程度の噂を追加質問への回答に利用できる。具体的な噂の出所・目撃者・買い手は未決。
- 普段の余裕ある軽口で、情報にも値段がつくという商売の話として扱う。意味深な沈黙、急な話題変更、過剰な強調、嘘による誘導は避ける。知っていることは素直に答え、知らないことは知らないと言う。
- 質問の内容に応じて情報の精度を上げる。既知の危険があれば正直に伝える。調査や接近を義務にせず、花の採集や地図の仕事を優先してよいと伝える。
- 真相を推理された場合は否定して矛盾を作らない。PCが鯨を名指ししたら「そういう話もあるのかい？ 俺には確かめようがないね。どこで聞いたんだい？」等、本人の知識に応じて答える。PCが別の情報源から鯨を知ることは妨げない。
- 通常の質問への返答に判定は不要。〈看破〉等を求められたら、成功時には商売上の関心と実際に確証がないことを伝える。判定で本人が知らない事実を獲得することはない。失敗を理由に偽の真相を与えない。別の情報源を調べる行動は通常どおり裁定する。
- 追加質問が出なければ、こちらから説明を重ねない。帰還後にPCの実際の目撃談を聞いて初めて、情報の価値を判断する。鯨を見なかったとしても、他の有用な情報の買付を否定せず、花の基本報酬も損なわない。

|---|---|
| 妙な話って何だ？ | 「あの湖で妙なものを見たって話が、以前からあってね。もっとも、人によって話が違うんだ。俺も何が本当なのか知らないよ」 |
| 具体的に何を見た？ | 「何か大きなものが動いたとか、そんな話さ。地下じゃ見間違いも珍しくないからね」 |
| 危険な魔物なのか？ | 「そこまでは分からない。安全だと請け合うつもりもないよ。わざわざ探しに行く必要はないさ」 |
| なぜ情報が欲しい？ | 「おや、情報だって立派な商品だよ。欲しがる客を見つけるのは俺の仕事さ」 |
| 何か隠しているのでは？ | 「もっと詳しく知っていたら、もう少しまともな仕事として頼んでいるさ。だから、あんたらの目で見た話が欲しいんだよ」 |
| いくら払う？ | 「何を見つけたかによるね。場所や様子を記録してきてくれれば、値段もつけやすい」 |
| 鯨のことか？ | 「そういう話もあるのかい？ 俺には確かめようがないね。どこで聞いたんだい？」 |

買付の最低条件・金額が決まった段階で、報酬の質問への回答を更新する。何を知るNPCなのかは今後の設定確定時に整合を取る。伏線を守るためにPCの調査成果や知識を無効化しない。
