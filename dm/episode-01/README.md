## 2026-11-23 作者決定：旧パーティーの年始の花便りとベルの善意による依頼

> **現行採用方針**。本節は、2026-11-23の対話で決定した「今年も、あの花を」ルートの設計上の正本。前段の老夫婦・押し花・ベルが正式依頼を仲介する案より優先する。名前・年代・細かな演出の未決事項は本節の末尾に列挙する。

### 旧パーティーと花の約束（採用）

- **過去**：かつて冒険者のパーティーが、同じ地底湖で年渡の鯨と空雪花の光景を目撃した。その仲間たちの間に、**花を通してつながる約束**が残った。
- **現在**：当時のパーティーは解散し、メンバーの**一人**が毎年、昔の仲間たちに**空雪花の生花を添えた年始の便り**を送っている。日本の年賀状のような季節の挨拶であり、押し花を作ることは前提としない。
- **主題**：花は特定の夫婦の恋愛や個人の思い出ではなく、**元パーティー全員の約束の象徴**。離れて暮らす旧仲間たちの人生のつながりを表現する。過去のパーティーと、今から冒険を始めるPCパーティーが重なる。
- **鯨**：昔の一行も、現在のPCたちも、鯨を見るために地下湖を訪れるわけではない。昔の差出人が毎年鯨に会っているわけでもない。鯨は基本的に冒険者に構わない。**鯨を見たパーティーには翌年幸運が訪れる**という採用設定と接続する。

### ベルが自発的に依頼する（採用）

- **ベルは配達員**として、差出人が毎年、同じ旧仲間へ花便りを送る習慣を知っている。毎年のやり取りを通して、その便りが大切なものだと察している。
- **今年は花を採りに行くのが難しくなった**。年齢による体力の変化、道中への比較的弱い魔物の定着などは理由の候補であり、具体的な原因は未確定。
- **依頼主はベル自身（2026-11-26作者明言）**。元冒険者から依頼されたのでも、花を届ける約束をしたのでもない。ベルが自発的なお節介・善意から、自分の判断と費用で花を採ってくれる冒険者を雇う。元冒険者は依頼の当事者ではなく、花の贈り先である。ベルの人物像（忙しいが目の前の人のために動く）に沿う。ベルは探索に同行しない。
- **情報不足には物語上の理由がある**。ベルは配達の事情・花の名前や贈り物としての特徴を知る一方、地下湖への詳細な地図、開花前の草の姿、月光による開花の仕組み、昔の鯨遭遇の全貌は**知らない**。知っている範囲は正直に話し、故意に秘密を伏せる人物にしない。
