## 4. 特殊裁定（下記の追加値は第一話限定の提案）

|---|---|

| 観察・記録 | 基本の目撃は自動。知覚DC10／自然DC12は輪郭・進行・鯨に似た生物等の追加情報だけ |
| 射撃・攻撃呪文 | 射程・遮蔽・対象・状態を照合、AC14。命中ダメージ・効果はそのまま。部位ごとのAC/HPを新設しない |
| 近接・接触魔法 | 最寄り体表までの距離、高さ、視界。実際に届けば通常処理。通過待機・飛行・跳躍を認める |
| Grapple/Shove | 通常の素手は対象が一段階大きいまで。中型/小型は超巨大に不可。別の魔法・特殊能力の条件を確認 |
| Jump/飛行 | 高跳びは助走10ft＋3+STR修正ft（最低0）、腕の到達は身長1.5倍を加味。残移動・高度を確認。装備・魔法は各効果どおり |
| 触れる | 届く安定姿勢なら判定不要。滑空中に体表へ飛び移るなら下記。触れただけでダメージ・強制魅了・治癒なし |
| 正式な騎乗 | 相手が承諾し適切な身体でサイズ差を満たし5ft以内、移動の半分を消費。鯨は訓練なしの独立騎乗。PCが進路を操作しない。通常は意に介さず乗せるためには有効な働きかけが要る |
| 非合意のしがみつき | 騎乗でもGrappledでもない第一話特殊アクション。体表に届き片手空き、ActionでSTR(Athletics)又はDEX(Acrobatics) DC13。成功で体表に留まる、失敗で元の安全な足場があれば留まり、空中なら落下。位置を記録。通常遊泳で毎ターン判定しない。急なロール・振りほどき・衝撃時のみ同DC13を再判定（下記の振りほどきと二重に課さない）。離すのは任意。体表への移動は登攀扱い、PCの移動を消費。鯨の速度を0にしない |

| Influence | 通常は無関心。安全な要求には承諾、不確実な要求は公式InfluenceのDC・態度、不合理な要求は拒否。魅了は友好・命令服従・騎乗承諾を自動にしない |
| 退避 | 実位置の視界と通行を処理。普通に退くのに判定不要。隠れるなら通常の条件・Hide、鯨に見つからないこと自体は目的ではない |

| 落下 | 10ft毎1d6（最大20d6）、ダメージがあれば伏せ。水面への落下はリアクションを使うDC15 Athletics/Acrobatics成功で半減。例20ft→2d6、60ft→6d6。落下距離は実際の高さ。警告し事前に降りる選択を与える |

### 4.1 自己防衛（優先順、提案）
原則は無関心→離脱。軽微な負傷で進路が変わらなければ遊泳、追撃や報復をしない。反復攻撃、明確な拘束、痛みで離脱を選んだ場合は通常移動＋必要ならDash（計240ft）またはDisengage（120ft、機会攻撃を避ける）。行動不能なら行動なし。移動不能ならその場で効果の終了条件を処理。条件を満たすなら通常のDodge、拘束解除等。方角は空いている水面・空間、無理にPCの頭上を越えない。HPの閾値や攻撃回数で罰を自動発動しない。
- 振りほどき（Action、第一話特殊裁定）：実際にしがみつく対象を1体選び、対象はSTR又はDEXセーヴ（対象選択）DC15。成功は保持、失敗は鯨から離れて実際の足場／空中へ。直接ダメージなし。高所なら落下。事前に体を揺すって離脱を促す描写を行う。通常の独立騎乗であれば公式騎乗ルール（強制移動・伏せのDC10など）を優先。乗せる意思を撤回した際は安全な降り方の機会を与える。振りほどきとロール判定を同じ原因で重複させない。
- 押し退け（Action、提案）：逃げ道を塞ぐなど切迫した危険時、近接10ft以内で実際に届く1体、STR/DEXセーヴ（対象選択）DC15。失敗で鯨から離れる方向10ft＋伏せ。成功は変化なし。直接ダメージなし、障害・落下は実地形。通常のShoveでなく独自能力。飛行経路を変えられるならこちらも不要。
- 尾の打撃（Action、最後の手段・提案）：拘束され離脱不能、なお攻撃が続き生命に差し迫る危険がある時のみ。尾の位置から10ft以内、1体、近接攻撃+9（暫定固定値、習熟なし）、2d6+9殴打（平均16）。多重攻撃・範囲攻撃・伝説的アクションなし。遮蔽と状態を通常適用。命中でLv2が0HPになり得ることを事前に警告。遠距離射手を殴るために接近しない。行動不能中は使用不可。通常の機会攻撃も防衛・離脱優先で使用しない。
- 意図しない実衝突は標準軌道に追加しない。例外的な強制移動・落下では体積と着地点から危険を宣告、逃げられるなら実移動・Ready、突然の避け得る衝突はDM裁定DEXセーヴDC13、失敗2d6殴打＋伏せ（成功半減・伏せなし）の仮値。巨大死体の直下などこの仮値で表せない危険は状況に応じ公正に裁定。通常の落下ダメージを重複適用しない（落下した者自身の通常落下は別）。

## 5. 花弁の拾得・記録（提案）
FL-01：成熟花の花弁1＋小果実1が一体、1株最大5。若齢花は散布しない。果実のみ微光。R17b以降、実際に降る散布体がいる場所で拾える。鯨が発光しなかった、照射されなかった区域には散布体を発生させない。
- 地面の安全な場所：一個は通常の物品操作、数個を集めるなら1回の利用アクション（戦闘中）、時間制約のない余韻では自動成功し実際の数を記録。収集のための反復判定なし。大量採集は実時間と分布を確認。
- 空中：手が届く流れなら捕まえる。流れが速く不確実ならDEX(Sleight of Hand) DC10（提案）で1個。失敗は通り過ぎるのみ。届かない花弁は移動・道具・魔法で近づける。
- 瓶/袋に保存可。濡れ・損傷は実際の扱いを記録。残光は短い描写にとどめて発光時間・照明半径・栽培成功・薬効・売値を確定しない。光源アイテムではない。若齢の生花の納品数には加えない。現物は研究・目撃の補足資料になり得るがE01-03の買付条件を変更しない。
- PLが映像だけで見た花弁や鯨はPCの成果にならない。少なくとも1人の現地目撃の有無と各人の見えた範囲を記録。幸運の厳密な部分目撃条件は未決のまま、パーティー単位の採用設定を維持。

## 6. 上映条件（採用A〜Dを運用化）
| 接続 | 条件 | 接続台詞 |
|---|---|---|
| A 直接 | 現在の遊泳・開花・散布・退場が成立し観察可能 | 「鯨はそのまま月光の方へ向かっていきます」 |
| B 俯瞰 | 現在の現象は成立、PCは退避・視界外等 | 「ここからは皆さんの視点を離れ、湖で起きた光景です」 |
| C 過去 | 今日の現象が不成立・大幅に相違・確認不能、元冒険者に会える | 「昔、仲間とあの湖で不思議な光景を見たんだ」 |
| D 卓外 | C相当だが面会なし/帰還不能等 | 「今日とは別に、かつての湖の光景をお見せします」 |
同一映像全編1回、希望による停止・スキップ可。A/Bは直近の行動と効果が確定し、残る経路で起きることを裁定できる時だけ。未来の行動を勝手に封じない。途中の宣言は停止して現在位置・世界時刻に戻し、未確定部分を裁定。既に画面に流れた映像も実結果と矛盾すれば再現/先行イメージとして訂正し、同じ動画をもう一度流す義務なし。中断で今日の後半が不成立になった時はその場で過去の光景に視点を変更する旨を説明するか、終了まで保留。シルエット・P0・傷の省略は演出、実際に採った花や傷は戻さない。騎乗中・追跡・集中効果が未解決なら先に裁定を進め、重大な相違ならC/D。鯨の一時拘束解除後に通常光景が成立するならA/B。軽微な差異と発光・散布・退場の不成立を区別。
