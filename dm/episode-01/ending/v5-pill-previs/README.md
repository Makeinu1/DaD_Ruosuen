## v5.0 決定版の統合ポイント（これまでの全フィードバックを集大成）

1. **導入・突進（v4.0 継承）**：`C3` 正面直進膨張 → `C4a` ランタン脇スレスレ引き上げ → `C4b` 闇と『小さく静かな眼』の 1.8 秒無音。
2. **開花〜大花吹雪の自然接続（v14.9b 復活 R10→R12→R13）**：`C5b` 地表 20cm 超低空の一斉開花ウェーブ（足元から石橋の苔の上まで！）→ `C6a` 離陸 1.0 秒重力静止 → 地上から上空 220m 大空洞へ連続チルトアップし、**空間を満たす 3 層大花吹雪** へ鳥肌級に自然接続。
3. **背景美術（1+3 遠近レイヤー融合）**：
   - **中景**：水没した旧時代の崩れた石造アーチ橋（中央崩落口＋銀リム光＋苔上の開花＋湖面の上下対称反射）。正本 [world/01_世界の骨格.md](../../../../world/01_世界の骨格.md) と 100% 整合（大断裂で沈んだ旧王国の石橋／星路の失われた巡礼路）。
   - **間の仕切り**：水平線付近の青銀色の空気遠近ミスト。
   - **最遠景（左右外枠のみ）**：霧の奥に沈めた巨大な天然鍾乳石柱（中央の白鯨＆満月の抜けは完全無柱、カメラ並走時に二重視差を発揮）。
4. **大空間の遊び芝居（v14.9b × v4.0 融合）**：`C6b` 360° 緩やかバレルロール＆崩れた石造アーチ橋くぐり → `C6c` 220m 大空洞×1+3 融合決定画の 40° 遊びバンク大旋回 → `C6d` 4人へ寄り添う 22° 優しい一瞥（0.6x スローの静かな間）。
5. **別れ・満月への溶解（v14.9b 復活 R17b→R18）**：`C7a` 背中越し見送り＆残された雪の降り始め → `C7b` **85mm 真横望遠** で巨大な満月の前を滑空しながら **尾びれ→胴体→胸びれ→最後に頭部** へ滑らかに溶け還る → `C7c` 本物の冬の雪 → `C8` C1 完全同一構図の最後の一枚と波紋。
