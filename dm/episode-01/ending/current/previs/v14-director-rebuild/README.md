## 時間の扱い（v14の規則）

鯨は1本の連続した世界時間τの経路を泳ぎます。各カットは `τ = τ0[カット] + (t − カット開始)` で世界の一区間を切り取ります。カット間でτ0が飛ぶところが**時間省略**です（R06→R07、R08→R09、R09→R10、R11→R12、R14の前、R16→R17、R17→R18、R18→R19）。マッチカットで続けるところ（R07→R08、R12→R13、R14→R15→R16）はτが連続します。

主なイベント（世界時間、`v14-QA.json` に全件）：浮上 22.2 s、PC頭上 79.0 s、月光に触れる 88.2 s、S1基部 111.4 s、岬の先端 125.1 s、x=0通過 156.3 s、下の岩縁 206.7 s、上の岩縁を尾が越える 217.5 s。

## 絵コンテに対する実装

- **鯨の演技**：泳速は4〜7 m/s。一漕ぎ5.6秒（力を入れるのは46%）→滑空。漕ぐたびに少し加速し、光の脈が頭から尾へ走る。速い一漕ぎはPC頭上通過の約2秒後の1回だけ。バンクは13°まで。頭上通過で16°だけ体をひねる（止まらない）。
- **点灯**：月光に頭が触れてから、頭→尾へ約4秒で点灯（第1相：氷青・銀・薄紫）。約6秒後から真珠・オパール色へ。消灯しない。白飛びしないよう明部を柔らかく圧縮。
- **花**：S1の岬に約4,800株（80%が成熟）。鯨の光が届いた株だけが、蕾→花茎が起きる→5弁が開く。R02の若い花P0だけは最初から月光の中で開いている。
- **花雪の二系統**：成熟株1株につき4枚の花弁と実。鯨の光（約65 m）の中で、35%の花弁だけが一定時間（6〜95秒）鯨の通った跡に沿って整列して流れる（導かれる花弁：回転しない、実が脈打つ）。それ以外と光の外は、湖上の大きな空気の流れ・渦・突風・鯨の航跡で舞う純粋な花吹雪（回転してきらめく）。鯨が去ると全部が自由落下になり、実の光は約5秒で消える。上の岩縁から70 m以上昇った花弁は夜空へ抜けて消える（タイトル回収）。
- **R19**：R01と同じ固定A。約67.5秒、最後の1枚がR01の一滴と同じ場所の水面に落ち、同じ形の波紋が広がる。実の淡い灯りが消え、68.9秒から約1秒で暗転（エンドカードなし）。鯨は画面にいない。

## プリヴィズ上の仮置き（設定として確定したものではない）

1. **天蓋と裂け目**：下の岩縁Z=190 m（設定の制御表）、上の岩縁Z=230 m、上は幅0.45倍の細い溝。月は方位+Y・仰角43°。月光は両方の縁を通る線だけが届く（半影約2.5 m）。
2. **P0の位置**：岸の近くで、月光の届く範囲の西端から1 m内側に自動配置。閉じた蕾は月光の外（約1.5〜2 m西）。
3. **鯨の退場経路**：上の岩縁を越えた直後に西へ水平に向きを変え、岩の上を泳ぎ去る。洞窟の底から見ると頭から岩縁の向こうへ隠れ、尾びれが最後に消える（R18の「尾びれが最後に消える」を幾何学的に成立させるため）。真上へ昇り続ける経路だと、開口部越しに見え続けて消えない。
4. **R16とR18のカメラ位置**：R16は湖岸の縁（18 mm、3.3 m前進して水面の上で止まる）。R18は「鯨が月を横切る」線上に置いたため、岸から約20 m沖の水面上1.8 mの固定カメラになっている。
5. **挿入カットの補助**：R10とR12は、カメラの前に同じ開花規則の花を足している（R10は70株、R12は主役の1株と周囲14株）。R12で花弁が1枚ずつ離れて約1秒浮く動きは手付け。R02とR12の地面の小石は質感の補助。
6. **R10の光**：鯨は画面外。画面の端から差し込む光を、鯨の位置からの柔らかいにじみで表現。
7. **R17とR18の天蓋**：岩の面を三角形の集まりで置き、鯨の光が届く範囲だけ照らす（届かない面は暗いまま）。

## 検証結果（2026-11-23）

QAの数値は `artifacts/v14-full70/v14-QA.json`。映像を全カット確認して直した点：

- 第0相（点灯前）の鯨が背景に沈んでいた → 夜空からのわずかな上方光と輪郭光を追加。
- 点灯後の鯨が白く飛んでいた → 発光を抑え、明部を柔らかく圧縮、ハロを画面上の大きさに応じて弱める。尾の色が茶色く沈む色相の穴を修正。
- R03で水中の鯨の形が陸の上に透けていた → R03は鯨を描かず波紋だけ。R04の暗い塊は水面の中だけに、形が読めないほどぼかす。
- 花弁の実の光が毎ステップ1に戻り、R19の水面に光の線が残っていた → 実の光は離脱時に1回だけ点け、鯨が去ったら全部消える。
- 導かれる花弁が鯨に貼り付いた雲に見えていた → 導かれるのは35%・期限つき、遅れは2.5秒以内、純粋な花吹雪は湖上の流れで大きく広がる。
- 1280×720で遠くの花弁が1ピクセルに潰れていた → 遠い花弁は解像度によらず幅の1/640の大きさで描く。
- R18で鯨が開口部越しに見え続けていた → 退場経路（仮置き3）とカメラ位置で、60〜62.5秒に鯨が月の前を通り（月は鯨が離れると現れる）、61.3秒ごろから頭が岩縁の向こうへ隠れ、約64.6秒に尾びれが最後に消える。
- R19の時間省略を世界時間で+300秒にし、舞っていた花弁はすべて着地した状態から始まる。
- R02が2秒間まったく動かなかった → P0が数ミリ揺れる（洞窟のわずかな空気）。

## 未解決・次に見る点

- **頭上通過の離隔**：R07〜R08で、尾びれの先がPCの目から最短約3.6 m（胴の中心は目の約8 m上）。「体がフレームを超える」近さとしては成立するが、近すぎると感じる場合は頭上の経由点を数m上げる。
- **R08**：振り返りの画で鯨の尾が画面上端に切れる時間がある。速い一漕ぎで月光へ向かう方向が読めるか、作者の判断が必要。
- **R02**：P0の花は読めるが、背後の閉じた蕾は暗く小さい。初見で「月光だけが花を開く」と読めるかはアニマティックで確認。
- **R19**：固定Aは18 mmの広角なので、最後の1枚と波紋は画面の中で小さい（R01の一滴と同じ大きさ）。韻としては合っているが、読めない場合は固定Aを保ったまま花弁の落下を手前に寄せるか、R19の前に寄りの挿入を足すかを判断する。
- **R16**：鯨は全景の中で画面幅の約8%。「全編で最も明るい頂点」としては花雪の密度と明るさがまだ足りない可能性がある。
- **R17**：裂け目の壁の三角形が細かくちらつく。本番では岩のモデルと照明に置き換える。
- **鯨の色**：オパール色は胴の位置で色相を変えるだけの簡易表現。本番の質感ではない。
- **音**：なし。v9の音の設計（R15〜R16で主題の全奏、R18で最後の大きな和音、R19は水滴とピアノの一音）は未検証。
- **見えない部分の扱い**：天蓋の向こうの鯨は三角形の中心で隠すかどうかを決めているため、岩縁の境目で数フレームだけ欠ける面がある。
