## 今回仮決めした演出

- 任務達成の安堵 → 湖の異変 → 巨大な鯨が現れる → **冒険者のほぼ真上を通り過ぎる（敵意の芝居なし）** → **陸地上空で月光を浴びて自ら輝く** → 光でS1岬の成熟花が咲き、白・金の花吹雪が舞う → 高空遊泳 → 一本の非対称な裂け目から尾まで去る → 静寂。
- **カメラは静止主体**。動かすのはN08の約15°の緩いパンとN14の約5°の上向きティルトだけ。その他は静止撮影点を切り替える。N01/N17は同一の固定A。
- **70秒・17ショットは第一編集案であり最終ロックではない**。カット数や長さは仮アニマティックの結果で調整する。
- **旧C08の一瞥・旧C09のフル背面ロールは上映必須ではない**。原画の作者採用・保管は維持。
- 旧C14の全追走リボン化は採用しない。P0若齢花は散布せず、成熟S1の**本物の花弁＋小果実**が離れ、果実だけ微光を持つ。
- 月を巨大にせず、遠い洞窟壁は最後まで暗く残す。N17の対岸・多段棚・水晶状物体は削除し、N01と背景を揃える。
