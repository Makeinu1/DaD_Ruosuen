### 確定した最新ビジュアル・演出仕様（Gate ①〜⑤ 反映済み）

- **地形・洞窟（`ENV-02` 準拠＋作者確定）**:
  - **横穴ゼロの完全閉鎖地下空洞（幅 450m × 奥行 620–700m × 天井高 185–190m）**。もともと広い地下空洞に渓谷が形成され水が溜まった地形。
  - 天井中央を縦長に割る **「峡谷型」裂け目** から満月と星空が見え、月光の柱が岸辺の `P0` へ差し込む。
  - 暗い黒曜石のような **鏡面湖（300m × 500m）** と、右奥に **退場 C 用の岩岬 `R1`** を配置。
- **年渡の鯨（`WH-01 v2.0/v2.2`、全長 24.0m）**:
  - 無斑・無瘤の滑らかな体表、長い胸びれ、小さな背びれ、静かな暗い瞳。**布・ベール衣・リボン等の装飾は一切なし。**
  - **3 段階クロマティック自発光**（月光を浴びた後は鯨自身が移動光源になり、退場時も消灯しない）：
    - `Phase 0 (0–37s)`：未発光の濡れた濃紺肌＋瞳のピンポイント月光反射
    - `Phase 1 (37–46s)`：月光接触で吻先から尾へ走る **氷青 × 銀白 × 紫（Ice-Cyan × Moon-Silver × Lavender-Violet）** の有機的発光波
    - `Phase 2→3 (46–90s)`：立体感を保った **真珠オパール薄膜発光**（氷青 → 白真珠 → 淡い桜桃 → シャンパンゴールドの虹彩変化）
- **空雪花（`FL-01 v0.8`）**:
  - 岸辺 `S1`（約 `5,059 m²`）を覆う **繊細で小さな 5 弁白花（径約 4.5cm・背丈 6–8cm）の濃密な群生**。
  - 未照射の閉じた蕾は乾燥雑草のような灰褐色。開花後は本物の 2cm 透過花弁＋微かに黄金へ光る 2–3mm の種子が、重力に逆らう **「逆さ雪」** として空洞全体へ舞い上がる。
- **視点・カメラ哲学（PC行動非固定・A+C ハイブリッド）**:
  - プレイヤー 4 人のキャラクター外見・行動は固定しないため、**PC の姿は映さず「カメラ＝冒険者自身の目線（POV）」** に徹する。
  - 前半（`0–46s`）は地上の冒険者目線に縛って静寂と畏敬を極限まで溜め、**Cut 4（正面寄り 20° 睥睨ドアップ＋2.5 秒ホールド）** で息を呑む視線交差を作る。
  - 後半（`46–66s`）は舞い上がる黄金の花弁に乗ってカメラが **重力から解放（離陸）** し、真珠オパールの鯨との **空中並走（Cut 7A）→ 18mm 空洞大パノラマ＆水鏡シンメトリー（Cut 7B）** で最大のカタルシスを作り、終幕（`80–90s`）は冒頭と完全同一の地上固定カメラ `Cam A` へ帰還する。
- **作品の感情目標**: 「来年もみんなで一緒に冒険しよう」。
- **音響設計**: 水滴・湖面・遠い鯨の声・風・オリジナル音楽を別トラック（`-14 LUFS` マスタリング）。鳴き声は開花原因ではない。既存曲の無断使用なし。

### 現行 90 秒・10 カット構成（V7 ディレクターズカット）

| Cut | 時間 | カメラ / レンズ / 動き（1カット1意図） | 内容・演出 |
| :--- | :--- | :--- | :--- |
| **Cut 1** | `0–10s` | **Cam A 完全固定 / 20mm**（動きゼロ） | 暗い完全閉鎖地下空洞、頭上の峡谷型裂け目から `P0` だけに落ちる月光。終幕（`80–90s`）と完全同一構図。 |
| **Cut 2** | `10–20s` | **Cam B 湖面俯瞰 / 35mm**・極低速プッシュイン | 鏡面湖に広がる波紋と、水面下を静かに手前へ迫る 24m の巨大な黒い影。 |
| **Cut 3** | `20–26s` | **Cam C 冒険者目線 (`Z=1.8m`) / 24mm**・緩チルトアップ | 音もなく水面から浮上し、未発光の濡れた巨体が手前岸辺の冒険者側へ接近。 |
| **Cut 4** | `26–31.5s` | **Cam D 睥睨ドアップ / 42–50mm**・ほぼ固定（2.5sホールド） | 正面寄り 20° から巨大な吻先と静かな瞳がフレームを覆う超近接。敵意のない太古の視線がプレイヤーと交差する溜め。 |
| **Cut 5** | `31.5–37s` | **Cam E 岸辺引き / 22mm**・緩パンフォロー | 視線を外し、長い胸びれを優雅にしならせて岸辺から引き返し、頭上の月光柱へ上昇。 |
| **Cut 6A** | `37–41.5s` | **Cam F 点火 / 20.5–35mm**・静かな見上げ | 月光に触れた瞬間、吻先から尾へ氷青×銀白×紫の発光波（Phase 1）が走り、岸辺の花々が波状に開花開始。 |
| **Cut 6B** | `41.5–46s` | **Cam G 水鏡ローアングル (`Z=0.45m`) / 24mm** | 繊細な白花群落の開花と黄金種子の浮き上がり、鏡面湖に映る対称の鯨と満月。 |
| **Cut 7A** | `46–54s` | **Cam H1 重力解放・空中並走 / 28mm** | 地上から離陸し、真珠オパールの鯨の斜め後ろを並走。黄金の花弁が前景を高速パララックスでかすめ抜ける高揚感。 |
| **Cut 7B** | `54–66s` | **Cam H2 神視点大パノラマ / 18mm**・スロープルバック | 450m 空洞全体 × 峡谷満月 × 鏡面湖 × 満開の花畑 × 3,000 枚の逆さ雪を一望するクライマックス。 |
| **Cut 8** | `66–80s` | **Cam I 退場 C 見送り / 24mm**・ほぼ固定 | 発光したまま右奥の岩岬 `R1` の背後へ泳ぎ去り、地形遮蔽で光がゆっくり引いていく（正本 Exit C）。 |
| **Cut 9** | `80–90s` | **Cam A 完全固定 / 20mm**（`0s` と完全同一構図） | 冒頭と同じ固定画へ帰還。鯨は去り、足元に残る花と微かな花弁の余韻だけが体験を暗示する。 |

## 過去の履歴（アーカイブ：旧 60 秒 11 カット案・旧 10 カット案）

- **2026-11-19 旧 60 秒 11 カット構成（CAM-02 v0.3）**: `A 0–5 → B 5–8 → C 8–12 → D1 12–17 → D2 17–25 → E 25–31 → F 31–38 → G 38–44 → H 44–48.5 → I 48.5–51.5 → A 51.5–60`。2026-11-21 に「溜め」「接近・睥睨・引き返し」「重力解放・空中並走」を十分に効かせるため **90 秒 10 カット構成（V7）** へ拡張・統合した。
- **2026-11-19 初期 10 カット案**: 月インサート独立・60 秒想定の最初期案。以降は上記の現行 90 秒 V7 仕様を正本として参照する。
- **確定済みの歴史的決定（現在も継承）**:
  - 依頼達成後に広大な地底湖で偶然出会う（鯨探しが依頼ではない）。
  - 独立翼状種子ではなく本物の花弁＋淡金色の果実（種子）を散布。
  - 月光接触後は鯨自身が移動光源となる。
  - 退場は C 案（岩岬 `R1` 背後への地形遮蔽）、終幕は A 案（冒頭と同一固定カメラへの帰還）。
