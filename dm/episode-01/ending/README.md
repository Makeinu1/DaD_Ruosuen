## 仮決定と未承認の区別

- **仮決定した方向性**：恐怖から神秘への感情曲線、頭上通過→陸地上空の月光、自発光と開花の因果、白・金の花吹雪、固定主体でパン1回＋微ティルト1回。
- **最終確定ではないもの**：70秒／17ショット、具体的なレンズ・XYZ値、原画の本編採否、実際の映像のカット点。低解像度アニマティックで調整する。
- **必須にしない**：旧C08の一瞥、旧C09のフル背面ロール。旧原画の作者採用は保管。
- **固定する制作規律**：冒頭と終幕は同一カメラ、月は不自然に巨大にしない、洞窟奥は闇のまま、S1だけ成熟散布、P0若齢花は散布しない、果実のみ微光、一本の非対称な裂け目、エンドカード無し。
