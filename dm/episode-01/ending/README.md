# 第一話エンディング『空に降る雪』（仮題）

**DM専用・ネタバレ注意。プレイヤーは閲覧しないこと。** 2026-11-19時点の会話の統合記録。逐語録ではなく現在値および重要な変更履歴。公開用原稿とは独立。

## 決定した演出・設定

- 初回冒険は年の瀬のルオスエン。複数の依頼（花、虹色の魚、凧とオーロラ）から選び、依頼達成後に同じ広大な地底湖で巨大な年渡の鯨と偶然出会う。鯨探しが依頼ではない。別ルートの演出を混同しない。
- 花ルート「今年も、あの花を」では老夫婦の依頼で空雪花を採集。若い花は散布しない。谷の裂け目からの月光で花が開く。
- 年渡の鯨は真珠白と青灰の自然な体表、長い胸びれ、小さな眼、腹部の溝、二葉の尾。空をゆっくり泳ぐ。神・使者・報酬を授ける存在と断定しない。観察者と目が合ったような瞬間。PCの外見・反応・行動を固定しない。
- **月光を浴びた後は鯨自身が光源になる（作者確定）。** 月光の光線から離れても自ら発光し、空雪花に光を届ける。鯨が常に光線内にいる必要はない。発光の持続時間・機構は未決。
- **退場C案採用。** 湖に戻らず地下の奥へ泳ぐ。張り出した岩壁の背後へ姿と光が遮られ、湖が暗くなる。鯨自身の消灯を描く必要はない。実際の目的地は見せない。天井の裂け目と退場経路は別に設計する。
- 空雪花は5枚の本物の花弁が成熟した果実を伴い舞う。黄金色の桜吹雪・逆さ雪のような大量散布。花の詳細は [flower.md](flower.md)。
- 終幕A案採用：冒頭と同一のカメラ・背景・基本光量。鯨が去り、花弁は散り、葉・茎・萼が残る。あの光景が夢だったかのような余韻。花の差分だけが体験を暗示する。実際に夢だったと断定しない。
- 作品の感情目標は「来年もみんなで一緒に冒険しよう」。60秒、16:9、24fps想定、台詞・字幕なし。青銀色から淡金色を経て墨紺へ。手描き劇場アニメ・ガッシュ風。

## 現行10カット（仮尺・撮影設計で変更可）

| CUT | 時間 | 内容・演出 |
|---|---|---|
| 01 | 0–5 | 暗い地底湖、右上の裂け目から細い月光。終幕と同じカメラ |
| 02 | 5–8 | 裂け目から見上げる月。月の直接描写はここだけ |
| 03 | 8–12 | 若い空雪花の接写。5弁、金の花芯、周囲の蕾 |
| 04 | 12–17 | 水面の波紋・巨大な影。鯨の全貌は隠す |
| 05 | 17–25 | 白鯨が湖面から静かに浮上、右上へ泳ぐ。浮上の生態上の意味は未決 |
| 06 | 25–31 | 同一個体の左側面の眼差し。擬人化しない |
| 07 | 31–38 | 月光へ進み発光開始。湖畔まで光が広がる。まだ散布なし |
| 08 | 38–44 | 蕾が開き、群生に広がる。成熟花の花弁・果実が離脱 |
| 09 | 44–55 | 地底湖の超広角、膨大な淡金色の花弁。最高潮。終盤から鯨が遠ざかる |
| 10 | 55–60 | 岩壁背後へ退場、光も遮られ、冒頭と同じ暗さ。58.5秒以後暗転（仮） |

音響は水滴・湖面・遠い鯨の声・風・オリジナル音楽を別トラック。静寂→予感→出現→親密→光→祝祭→静寂。鳴き声は開花原因ではない。既存曲の無断使用なし。

## 撮影設計への移行（作者方針）

既存原画は一枚絵・美術参照として採用。技術的な撮影用キーフレームとしては未確定。一貫したカメラ位置・向き・画角・地形・光源を優先し、必要に応じ再構図する。3Dプリヴィズを無理に実行しない。平面図、断面図、奥行き図、鯨の動線、固定月光と移動光源、カメラ位置・高さ・注視点・焦点距離・移動経路、開始終了フレーミングを制作資料として先に整える。カット数は仮。撮影軸は同じ湖畔側を基本にし、冒頭と終幕は同一カメラ。退場時は岩壁で姿と光を遮る。[退場C案の平面・側面概念図](exit-c-study.svg) を参照する（座標・光量・撮影軸は未検証）。

**次工程：地底湖 撮影設計シート v0.1。** 地形寸法は撮影用の仮値と世界設定を区別する。撮影設計→必要原画の再制作→仮編集→生成テスト（開花・散布・発光・鯨の形態維持）→本編集。動画生成サービス、費用、実機動作、60秒映像本体は未検証・未制作。

## 変更履歴の要点

- 当初9カット→月の独立インサートを追加して10カット。鯨と月本体を無理に同一画面に置かない。
- 白い独立翼状種子→淡金色の種子→本物の花弁と果実を散布。旧案は不採用。
- 月光を増幅するだけの存在という解釈→接触後に移動光源となる設定を確定。
- 退場A（距離）／B（潜水）／C（地下奥で遮蔽）からCを確定。
- 終幕画は花・蕾だけを局所編集して散らし、月光を少し減光した版を採用。既存冒頭との一致は撮影設計で確認。
- 原画を先に作る工程から、空間・カメラ設計先行へ変更。
