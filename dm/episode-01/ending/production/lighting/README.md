## 照明の原則

月光は天井の裂け目Q=(45,66,85)から直射花P0=(3,-37,1.25)への固定軸。月の円盤を映すのはBのみ。湿潤な空気の柔らかな体積散乱・濃淡と拡散した返り光を描き、硬い境界の光柱にしない。見える散乱光と実際の直接照射域は区別し、散乱光のみで群落を一斉開花させない。

月光だけの段階は広大な空間の大半が闇。D1の遠方・天井の露出を抑える。鯨は接触前は非発光。接触後は銀白〜青白の移動光源となり、陰影と体型を保ち過露光しない。湖面反射・岩壁の照明は光源位置と遮蔽に連動させ、全洞窟を均一照明しない。退場しても消灯しない。R1/R2の遮蔽と距離で手前が暗くなる。花弁・葉・茎は非発光、離脱果実のみ微光（FL/FXで管理）。

A冒頭と終幕は同一カメラ・固定背景・光軸。60秒も月光は残る。暗転は編集工程で行い、A05原画に焼き込まない。QG4ではA01とA04/A05に背景差があるため、採用画の個別美術承認と固定背景の技術合格を区別する。
