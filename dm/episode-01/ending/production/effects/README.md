## 散布体と美術

花弁1枚（約2cm、乳白色、繊細な脈と緩い波打ち）と付け根の果実1個（2–3mm）が一体で離脱する。花弁は透過・反射光で淡金色にも見えるが自発光しない。飛散中の果実のみ微かな金白色の光を持つ。独立種翼、巨大光球、別個の魔法火花や星形粒子を追加しない。近接では実際の花弁形と回転、中景では小さな花弁、遠景は点状・サブピクセル。大きな近景のぼけはカメラ至近の実寸花弁で表現。

群落は全湖域ではなくS1から放出。成熟花1輪につき最大5個。未照射・若齢・残留花弁を終幕でも維持する。群落全体の離脱割合80%は全ての成熟花が必ず4枚失うという意味ではない。

## v0.2 モデルの仮条件

| 項目 | 採用した撮影用仮値 |
|---|---|
| S1面積 | 5059.5278 m² |
| 被覆割合／被覆域密度 | 0.6／100輪/m² |
| 照射割合／成熟割合 | 0.7／0.8 |
| 花弁数／離脱割合 | 5／0.8 |
| 累計放出予算 | 680001個相当（重み付き標本） |
| 粒子標本数／固定乱数 | 30000／1908 |
| 時間刻み／放出時間 | 0.05秒／42–45秒 |
| 主方向 | +Y、鉛直減衰・沈降項・揺らぎ |
| 仮の後流 | 鯨の1.2秒前の位置から12m以内だけ局所渦 |
| 果実微光 | 離脱後5–15秒に減衰する仮案、60秒で0 |

予算式：S1面積×被覆割合×密度×照射割合×成熟割合×5×離脱割合。旧概算の679996.8は5059.5m²での値、v0.2の680001は現行メッシュの面積による重み付き予算。画面の可視数や物語上の実数ではない。

| 速度帯 | 割合 | 水平速度 m/s | 初期鉛直速度 m/s |
|---|---:|---:|---:|
| 低速 | 65% | 2.5–4.5 | 1.5–3.2 |
| 中速 | 23% | 4.5–8 | 3.2–4.1 |
| 局所高速 | 12% | 8–11 | 4.1–5.5 |

強い局所流と渦は演出仮定。実際の流体計算ではなく、発生原因は未決。全粒子を鯨に吸着させない。同じseed・放出/気流条件・粒子IDでHIAと統合CAM-02へ接続し、カット境界で瞬間移動・群落追加を行わない。

高度帯合計と累計は丸めにより最大1異なる。48秒までに仮後流領域へ累計2063個相当、51.5秒には5259個相当（0.8%弱）。60秒も680001個相当が空中に残るが、果実平均相対微光は0。消光で粒子位置を削除しない。花弁の反射・遮蔽と果実自発光を分ける。
