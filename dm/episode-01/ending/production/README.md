## 2026-11-21当時のV7制作値（旧版・移植履歴）

- **当時のカット・尺・カメラ構成（現在は旧版）**：**V7 Blender 5.0 Cycles GPU・全 10 カット／90 秒（`2,160f @ 24fps`）**（詳細：[../README.md](../README.md)、[`v7_layout_master.json`](../video-pipeline/v7_blender_cycles/v7_layout_master.json)）。旧 `CAM-02 v0.3`（全 11 カット 60 秒）は履歴参照として保存。
- **共通地形**：`ENV-02 v0.4` 継承＋2026-11-21 作者確定（**横穴ゼロの 450×620–700m 完全閉鎖地下空洞**、天井高 185–190m を縦に割る **「峡谷型」裂け目** から満月と星空を望む、鏡面湖約 300×500m、固定光軸 `Q→P0`、`S1`、退場 C 用岩岬 `R1/R2`）。
- **鯨**：`WH-01 v2.0` 美術正本（無斑・無瘤・滑らかな体表、**布・ベール衣・リボン禁止**）、`v2.2` 技術プロキシ（全長 24.0m）。90 秒構成では `10–20s` 水面下の巨大な影＆波紋 → `20–26s` 浮上・手前接近 → `26–31.5s` **Cut 4 睥睨ドアップ（正面寄り 20°・2.5s ホールド）** → `31.5–37s` 引き返し → `37–46s` 月光点火 → `46–66s` 真珠オパール飛翔 → `66–80s` 岩岬 `R1` 裏へ退場（消灯しない）。
- **花**：`FL-01 v0.8` 準拠。岸辺 `S1` に繊細な 4.5cm 5 弁白花群落。閉花時は灰褐色（乾燥雑草色）、開花後は本物の 2cm 花弁＋黄金に微光する 2–3mm 種子が逆さ雪として舞う。
- **照明**：`LGT-02` 継承＋V7 更新。**3 段階クロマティック自発光**（`Phase 0` 未発光濃紺 → `Phase 1` 氷青×銀白×紫の波 → `Phase 2→3` 真珠オパール薄膜：氷青・白真珠・桜桃・シャンパンゴールド）。月の円盤は B 専用制限を解除し、頭上の峡谷型裂け目から各カットで自然にフレーミングする。
- **カメラ哲学（PC 行動非固定・A+C ハイブリッド）**：PC の姿・行動は固定せず、前半（`0–46s`）は冒険者目線 POV に徹する。後半（`46–66s`）は舞い上がる花弁に乗って重力から解放され、空中並走（Cut 7A）→ 18mm 空洞大パノラマ＆水鏡シンメトリー（Cut 7B）へ開き、終幕（`80–90s`）は冒頭と完全同一の固定カメラ `Cam A` へ帰還する。
- **FX**：`FX-01 v0.2` 概念継承。本物の花弁＋黄金種子が逆さ雪として空洞へ舞い上がり、終幕は名残の花と微かな余韻を残す（全株を裸にしない）。
