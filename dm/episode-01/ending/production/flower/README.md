## 制作で固定する事項

| 状態 | 制作基準 |
|---|---|
| 閉花 | 灰褐色〜灰緑の5枚の萼が乳白色花弁をほぼ隠し、うつむいて枯れ草に見える |
| 開花途中 | 根・葉の位置は固定し、茎上部が起き上がり萼と花弁が展開 |
| 若齢満開 | 花弁・萼・雄しべ・雌しべ・子房各5。散布しない |
| 成熟満開 | 同じ外形、花弁5枚・果実最大5個・萎縮した雄しべ5本。離脱前は非発光 |
| 散布途中 | 本物の花弁1枚＋対応する果実1個が一体で離脱。果実だけが微光、花弁全体の自発光や独立種翼は禁止 |
| 散布後 | 離脱した花弁・果実を失い、萼5枚・花托・茎・葉・雄しべの跡を維持。若齢・未照射・残留花弁も存在し得る |

六状態図譜の若齢花には6個の葯状先端が見えるが、図譜の誤差であり技術図の5本を優先する。器官配置図の番号は離脱順ではない。散布途中の残3＋離脱2、全散布後0は技術上の例であり、各花の散布率を固定しない。若齢から成熟までを映像の数秒で進行させない。

撮影用仮寸法：花径4.5cm、草丈6–8cm、花茎4–6cm、葉長3–4cm、閉蕾長1.5–2cm、花弁約2cm、果実2–3mm。絶対寸法・成熟期間・受粉・発芽・発光機構等の世界設定は未確定。

ENV-02 v0.4のS1約5059.5m²は配置範囲であり、全部が花で覆われる意味ではない。A/C/D1ではP0の直射花を例外として近岸群落は閉花。P0とGの成熟花P1は別株。Gで照射された成熟花が開花・散布し、FX-01 v0.2の粒子予算に接続。終幕で全群落を裸の花托にしない。PCの採集・行動を映画内で固定しない。
