## 現行差分制作の制約

- A固定カメラは(-14,-62,5.8447)、18.2573mm、yaw4.6723°、pitch9.1317°。A冒頭と終幕の画角・背景・水際・裂け目・岩壁・岩棚・根元は固定。Oは別視点。
- A01をピクセル固定母版とし、最新の植物領域で局所編集マスクを作成・合成する。旧v1.0のマスク外同一画素という条件を継承。花弁・茎・葉・根の寸法と位置は維持。未照射と若齢、散布済み成熟、残留花弁を区別。
- A04＝58秒。白鯨は地形遮蔽により見えず、発光自体は継続。P0若齢花は残し、成熟花のみ散布した状態。ごく僅かな果実微光は別FXレイヤー。
- A05＝60秒。A04と同一の合成母版から空中の果実微光だけを除く。月光は維持、花弁は消滅しない。暗転は原画に焼き込まず編集で扱う。A04/A05を独立した全景再生成で作らない。
- レイヤー設計はBG-A、M-OCC、L-MOON、P-START、P-END、W、L-W、FX-PETALS、FX-WATER。A02/A03は同じ母版に同一動作・粒子・光・遮蔽を合成する。実際の各レイヤーの分離・作成は未完了。
- 前セッションの方針に基づく再開順はAの差分整合→B/C流用照合→D1/D2/E/F/G/H/I/A02/A03を必要分だけ順に制作・検証。D1はCAM-02 v0.3の低位置投影、水面下の鯨、暗い固定月光、閉花群落を参照し、背景や天井を露出させ過ぎない。直近別スレッドのD1案3点は作者指摘により採用しない。新規生成は本移植では行わない。
