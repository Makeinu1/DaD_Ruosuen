## 引き継ぐべき制約

座標系X右・Y奥・Z上、湖面Z=0。Q=(45,66,85)、P0=(3,-37,1.25)、P1=(5.2,-37,1.25)。局所水域は196×132m、広域水域案は約300×500m、空洞制作範囲は約450×700m。Qは85m、奥の天井は150–200m案。R1/R2で奥と鯨の退場を遮り、T1段丘とS1近岸群落を共通参照する。P0の若齢花とP1の成熟花は別株。固定月光軸Q→P0を移動させない。

v0.4のQG1可視範囲図は、到着O 4.7%、48秒A 16.3%、57秒A 10.9%を示す。これは1m格子と三角形メッシュとの線分交差、月光65m・鯨光140mの仮条件による診断であり、物理照明・画角・暗視・反射を含む実視認率ではない。v0.2の旧数値とは区別する。

D1の原画ではCAM-02 v0.3の投影、固定月光のみ、閉花群落、全身水面下という条件を継承する。A01/A04/A05の背景残差はQG4に残す。ここでは新規作画・再設計を行わない。
