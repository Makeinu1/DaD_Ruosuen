## 現行統合本文（Notion最終版：FL-01 v0.8 / 2026-11-19）

六状態の新図譜（生成ID `81058094-1dd9-4047-abf1-c67e83a86786`、2026-11-19）は作者承認により美術参照として採用。器官数と寸法は本文優先。

空雪花（くうせつか）は月光により開花する地下の植物。年渡の鯨が月光を浴びて自ら光源となると、光の届く群落が開花する。若い花は開くだけで散布しない。成熟花は本来の花弁と小さな果実が一体になって離脱する。独立した種翼は存在しない。花・葉・茎自体は発光せず、飛散中の果実（種子側）のみ淡い金白色の微光を持つ。

| 器官・状態 | 基準（v0.8） |
| --- | --- |
| 花弁 | 5枚、乳白色、薄く繊細な脈と緩やかな波打ち、淡金色の中心。C採用画の外形と比率を正本とする |
| 萼 | 5枚、灰褐色〜灰緑、閉花時は白い花弁をほぼ隠す。枯れ草状でうつむく |
| 雄しべ | 5本、小さな淡金色の葯 |
| 雌しべ・子房 | 各5個、独立して各花弁に対応。果実は各子房に由来し種子を包む |
| 葉・茎 | C採用画の青緑の細長い葉、しなやかな茎。開花に伴い上部が徐々に起き上がる。根元と葉の位置・寸法は維持 |
| 散布体 | 本物の花弁1枚と付け根の小果実1個。成熟花から最大5個。果実のみ微光、花弁は透過光で淡金色にも見える |
| 散布後 | 成熟花は離脱した花弁を失う。葉・茎・萼・花托・雄しべの跡は残る。若齢花は散布しない |

- **撮影用仮寸法:** 花径 4.5cm、草丈 6〜8cm（開花時）、花茎 4〜6cm、花弁長 約2cm、葉長 3〜4cm、閉蕾長 1.5〜2cm、果実 2〜3mm。C採用画（`df827a35-d190-421f-8d1d-f2f9c87c566e`）を比率の正本とする（絶対寸法は撮影用で世界設定の確定値ではない）。
- **映像の6状態:** ①閉花（うつむく灰褐色の萼）、②開花途中（花茎が起き上がり萼と花弁が開く）、③若齢満開（五弁・五雄しべ・五雌しべ、散布なし）、④成熟満開（同じ寸法・花弁の付け根に成熟果実、雄しべは萎縮）、⑤離脱（実花弁と果実が一体で離れ、果実だけ微光）、⑥散布後（花托・萼・茎・葉が同位置に残る）。
- **群落:** ENV-02 v0.4 の S1 約5059.5m² を配置範囲とする（全域被覆の意味ではない）。最新 O 採用画（`4e9ab526-8082-41de-ab1d-c01f491f3229`）と A01（`c4cbebde-d90d-4fa8-af53-8c30dea1cc0b`）の密生量、灰褐色の閉花を美術基準とする。
- **未決事項:** 成熟に要する期間、受粉方法、果実と花弁の接続機構、採集後の保持、発光持続、光の閾値。初開花・受精後に閉じた状態で成熟が進み再開花で散布する説明は提案として維持。
