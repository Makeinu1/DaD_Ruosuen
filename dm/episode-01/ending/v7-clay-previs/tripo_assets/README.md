## 方針

1. `inputs/` に背景ノイズ・他パーツを除去した **単体 1024×1024 モデル入力 PNG** を格納。
2. Blender 5.3 MCP（`generate_3d provider="tripo"` / Tripo Studio）で有機素体・建築モジュールを生成。
3. Blender 上で尺度・原点・法線・眼球（多層球体差し替え）・水際シェーダーを仕上げ、コンタクトシート比較後に採用パーツのみ本体へ組み込む。
