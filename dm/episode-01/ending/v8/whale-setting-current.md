## 造形の固定事項

| 項目 | 共通条件 |
| --- | --- |
| 全体 | 全長24.0mの巨大な白鯨。水中だけでなく地下の空気中を、水の中のように泳ぐ。 |
| 顔 | 突起・瘤・牙・人間的表情を付けない。吻先は滑らかで、口元は自然。 |
| 目 | 小さく暗い眼。非発光時には月光の一点が反射する。**一瞥は敵意でも好意でもない**。 |
| 胴体 | 滑らかな皮膚と穏やかな腹側の溝。喉腹の畝が不自然に顔の先まで続かない。 |
| 胸びれ | 左右一対、長く滑らか。位置と取り付けを全ショットで一致させる。胸びれを増やさない。 |
| 背びれ | 小さい一基。 |
| 尾 | 一対の尾葉を持つ水平尾びれ。尾柄から連続し、ねじれや関節破綻を起こさない。 |
| 装飾 | 斑、瘤、布、ベール、体に巻き付くリボンを付けない。花びらの群舞は鯨自身の装飾ではない。 |

**制作の仮寸法**：全長24.0m、全展開幅14.8m、尾びれ幅9.0m、胴最大幅4.5m、胸びれ片側中心線約8.6m。3Dモデル全体の上下外接寸法5.673mと胴部最大厚4.44mは異なる指標である。これらは撮影用の基準で、全てが種としての生物学的確定値ではない。

## 発光の状態（v10の約80秒構成を優先）

| 状態 | v10の場面 | 見せ方 |
| --- | --- | --- |
| Phase 0 | C01–C10・月光に触れるまで | **自発光しない**。濡れた濃紺〜真珠灰の皮膚を月光の反射と縁取りだけで捉える。瞳は暗い。 |
| Phase 1 | C11（37–41秒を仮基準） | 月光に入った吻先から尾へ、有機的な光の波。**氷青・銀白・ラベンダー紫**。いきなり全身を均一な白にしない。 |
| Phase 2–3 | C12–C18 | **真珠オパールの薄膜的な自発光**。氷青、真珠白、淡い桜桃、シャンパンゴールドが立体形状に沿って変化。白飛び禁止。 |
| 退場 | C17–C18 | 自発光のまま天井裂け目へ昇り、距離と月光への重なりで小さく見えなくなる。**消灯はしない。** |

発光後は鯨が移動する光源になり、光が届く成熟した空雪花の開花を引き起こす。花びらは鯨の不思議な力に導かれるが、鯨の**鳴き声そのものは開花原因ではない**。発光の生理学的・魔法学的原理は未確定。

## 性格ではなく、画面上の振る舞い

- 鯨はプレイヤーの前で「ボス戦か」と身構えさせるほど大きいが、威嚇のために牙・攻撃・吠えを使う演出は不要。
- C08でいったん静止し、何を考えているかわからない瞳を向ける。
- C09で強く一漕ぎして背面ロールへ移る。この**一度だけ速い運動**が恐怖から驚異への転換点。
- それ以外は一漕ぎ→滑空。水中の浮力を感じさせる大きな半径の旋回。
- C15では湖上の高い位置へ戻り、C17–18で天井裂け目へ昇る。湖へ再潜水・岩岬の裏へ退場は現在の筋ではない。

## 原画間の造形チェック

- **C06–C08**：頭が迫るにつれて「近さ」と瞳の位置が連続するか。人間的な笑顔にしない。
- **C09→C10**：胴のロール方向、腹がどの程度見えるか、カメラの右寄り視点、尾の上下・ねじれ、右胸びれ位置。C10は顔を見せず、月光へ向かう。
- **C11／C11.5**：追加された胸びれや尾の分裂がないか。複数原画は別版として判定する。
- **C15→C18**：方向転換・高度変化・発光・尾の周期が途切れないか。
- 現在の生成画に見える光の筋を実在の余剰肢や腹側の溝として読み替えない。

## 保留すべき事項

生息域・来歴・寿命・知性の度合い・プレイヤーへ向けた一瞥の真意・発光の物理法則・裂け目を通る際の尾・胸びれの具体的姿勢・3Dリグと関節変形は未確定。決定と提案を混在させず、映画内で必要になった項目だけ検討する。
