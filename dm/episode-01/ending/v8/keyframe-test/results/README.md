## 置き方

- 画像はこのフォルダに直接置く。生成されたままの形式（PNG または JPEG）、16:9、できれば長辺 1920 px 以上。
- ファイル名：`<対象>_t<試行番号>[_e<修正番号>].<拡張子>`
  - 対象：`sheet`（鯨の清書シート）、`C08`、`C16`
  - 例：`sheet_t01.png`、`C08_t02.png`、`C08_t02_e1.png`（C08 の2回目を1回修正したもの）
- 失敗作も消さずに置く（どの症状が出たかが次のプロンプトの材料になる）。
- 1回生成・修正するごとに、下の記録表に1行足す。
