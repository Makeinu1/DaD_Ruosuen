**DM専用・プレイヤー閲覧禁止。** [試作手順](../README.md) で生成した画像と記録の置き場所。生成は Gemini、判定は Claude と作者が行う。

当面は Gemini が Google Drive の `results` フォルダと記録表に置き、Claude がこのフォルダへ移す。ファイル名と記録表の列は Drive 側も同じにする。

## 置き方

- 画像はこのフォルダに直接置く。生成されたままの形式（PNG または JPEG）、16:9、できれば長辺 1920 px 以上。
- ファイル名：`<対象>_t<試行番号>[_e<修正番号>][_<ツール>_<YYYYMMDD>].<拡張子>`
  - 対象：`sheet`（鯨の清書シート）、`C08`、`C16`
  - ツール：`gemini`、`chatgpt` など。方式の比較に使うので、付けるのを推奨
  - 例：`sheet_t01.png`、`C08_t02_e1.png`（C08 の2回目を1回修正したもの）、`C16_t01_chatgpt_20261121.png`
- 失敗作も消さずに置く（どの症状が出たかが次のプロンプトの材料になる）。
- 1回生成・修正するごとに、下の記録表に1行足す。
