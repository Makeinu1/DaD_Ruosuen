# 第一話・帰還編① 鯨が去った湖からモグラの寝床へ v0.1

> **2026-11-26作者採用。** 帰還の進行方針（静寂、最後の自由行動、安全な既知経路の短縮、街への帰還）を採用。具体的な読み上げ・帰還時刻・散布体の性質等は調整対象。対象は鯨との遭遇が終わった直後から街・モグラの寝床への帰還まで。NPCへの報告・買付額・伝承・元冒険者・カードの演出は次工程。採用済みの全編上映A〜D、地底湖探索、既知の安全な復路のシーンカット方針を維持。地理台帳・映像・生態正本を変更しない。

## 1. 目的
感情の頂点から静寂へ戻り、プレイヤーが自分たちの成果と体験を持ち帰る。新しい謎・戦闘・締切を足さない。通常ケースの卓時間3〜5分目標（未実測）、希望する探索・会話・残存危険の処理は別。自由行動を一度聞き、帰還宣言後は安全な既知経路を短縮する。

## 2. Scene 01 湖の静寂
通常上映Aの暗転後は数秒置いて、静かな湖の情景に戻す。実際に視認できた結果のみ描写する。
> 鯨の姿は、もうどこにもありません。水面には小さな波紋が残り、やがてそれも消えていきます。湖は、皆さんがここに来たときと同じように静かです。
> さて、どうしますか？

感想・会話・休憩・探索を自由に選択。PCの感情や台詞を指定しない。映像Bで離脱しているPCは実際の位置から再開し、C/D（過去の映像）はこの場面で上映済みと扱わない。鯨が拘束されている・負傷して離脱等のケースでは現実の状況を描写し、通常退場や散布が起きたと偽らない。

## 3. Scene 02 最後の自由行動
| 宣言 | 裁定 |
|---|---|
| 鯨の去った方を見る | 実際に見える開口・水面・空を返す。行き先や正体は断定しない |
| 空雪花を確認する | 摘んだ若齢花は長持ちし、成熟花の散布で消えない。未採集分は実際の状態 |
| 舞い降りた花弁を拾う | 散布が起き、到達可能な場所に花弁＋小果実の組があれば拾える案。普通の拾得に判定不要。光の持続、保存、生育、売価、魔法的用途は未決。拾得物を若齢の生花・カード用花と混同しない。湖面に落ちた最後の一枚を必ず回収できるとはしない |
| 群生地・経路・鯨の情報を整理 | 既に観察した事実は判定不要で記録。精密な測量は既存の湖探索の裁定。観察事実と推測を区別。映画のみの知識をPCの目撃に加えない |
| さらに探索 | 実際の地形・視界・時間に応じて処理。新しいイベントを強制しない。帰還は本人が選ぶ |
| 休憩 | 通常のD&Dの休憩と資源回復・作中時間に従う。安全を無条件で保証しない |
| 帰ろう | 帰路の選択へ。追加の判定・会話・調査を義務にしない |

DMは帰還前に採集した生花・蕾・散布体、地図の観察済み区間、目撃者と内容、負傷・消費品・未解決危険を確認する（短い確認、プレイヤーに報告書を書かせる義務なし）。地図・報告は実際の探索成果を反映し、報酬の確定や地図院の正式登録とは別。以前調べた場所に新たな白花があっても、その場の時刻と照射・散布結果に従う。

## 4. Scene 03 復路
「帰りは、ここまで通ってきた道を戻りますか？」と経路を確認。往路で安全と確認した道を使い、残った危険がなければ、洞窟→S34奥棚口候補→R65→R3→GATE→TERMINAL→HOMEを短い描写でつなぐ。S34と湖の実地接続は未確定。行きに通っていない分岐や、残った敵・再通過条件・崩落・追跡は実際に処理する。既知の安全な街道のD100再抽選は原則なし。作中移動時間・照明等の資源・荷物は保持。初回非会員HOME料金方針と会員無料を維持し、復路で同じ料金を再徴収する案は追加しない。
> 皆さんは来た道を引き返します。行きに目印にした岩や分かれ道をたどり、やがて整備された街道へ戻ります。道沿いの灯りが再び見えてきます。
> しばらく歩くと、ゲートに戻ってきました。

投影：湖→洞窟入口または街道→ターミナル（既存画像があれば流用）。新規素材を必須にしない。紙地図は実際の往復経路と発見・未踏の範囲を確認できるものにする。帰路に地図を完成させることを義務化しない。未知を既知に変えた成果は報告・今後の台帳更新で扱う。地図の追加開示範囲は別途決める。

## 5. Scene 04 街への帰還
> ホームに乗って地上へ戻ります。地下の静けさから一転し、街の人々の声が聞こえてきます。年の瀬のルオスエンです。

街の時刻・人出・営業状況は実際の帰還時刻に合わせる。夜明け・深夜・夕方を決め打ちしない。モグラの寝床を目指す場合は入口または卓に着いた時点で今回の範囲を終了。寄り道を認める。ベル/タッカーが必ず寝床で待つという新設定は付けない。報告の時間・場所・相手の反応は次工程。

## 6. 桜井式レビュー
既に達成した目的について同じ障害を繰り返す必要はない。帰還の価値は変化した視点（未知の道が分かる道になった）、仲間と成果を持ち帰ること。映像後の静寂と地上の生活音の対比で冒険が終わった実感を出す。既知道短縮は採用方針。追加の拾得・地図精度・返答例・台詞は試案。未決：実地形、時間、散布体の物性・用途、残存危険・料金の特殊事例、各NPCへの報告と報酬、実卓検証。
