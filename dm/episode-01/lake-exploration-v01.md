# 第一話・地底湖探索「まだ花だと気づいていない」v1.0 卓用統合稿

> DM専用。2026-11-26。作者が了承した探索の骨格、ベルの群生の伝聞、時間経過による自然開花のリカバリーを統合し、卓用の味付けを加えた完成候補。読み上げ・DC・仮時刻・配置は調整値であり世界設定の新規承認ではない。旧v0.4までの検討経緯・問答・机上テストは[編集前のGit履歴](https://github.com/Makeinu1/DaD_Ruosuen/blob/f662b6d0e6e463fe9c8e46860245966003b8781c/dm/episode-01/lake-exploration-v01.md)に保存。本稿は卓上進行の現行案として旧試案より優先する。第一話の全体設計、FL-01、映画、地理台帳を変更しない。

## 1. DM早見（このページだけで進行できることを目指す）

**目的**：ベルから依頼された白い花を必要な分だけ採る。タッカーへの地理・群生・採集情報は独立した任意の買付。湖での必須戦闘なし、必須判定0回。通常プレイで実卓15〜30分目安（早く終わってよい）。長い会話や詳細測量を自ら希望すれば延長。

**通常の体験**：到着→一輪→不足と群生の伝聞の違和感→同じ葉・蕾→調査済みの岩のそばに二輪目→知識・記憶・観察の判定（任意）→月光が次の蕾に届く→採集。
成功時は予想の検証、全失敗・推理停滞時は開花そのものをリカバリーにする。最初の一輪を摘む、蕾を持ち帰る、早く帰る、別の場所を調べる自由を認める。PCが見ていない情報は渡さない。原因の言語化はクリア条件ではない。

| 順 | 状況 | DMが返す情報 | 判定 |
|---|---|---|---|
| 1 | 湖に出る | 静かな広い水面・月光・灰褐色の草・見える範囲に白花なし | なし |
| 2 | 岸を探す | Aの白花一輪、葉・茎、照射状況 | なし（十分な観察・到達） |
| 3 | 他を探す | Bの目印と白花なし、草がまとまる。近接観察で蕾 | なし |
| 4 | Bが開花済みで再び見える | 先ほど調べた地点に白花がある（観察済みの事実を確認） | なし |
| 5 | 違いを考える | 具体的な知識・記憶・影の変化を一つ返す | 自然／捜査／知覚 DC10案、適切な方法を選ぶ |
| 6 | 次の照射 | Cの蕾が月光を浴び開花。成功・失敗で現象は変わらない | なし |
| 7 | 必要な花を採る | 実際に確保した若齢花・情報 | 普通の採集はなし |
| 任意 | 詳細調査 | 地図に書ける位置・分布・到達方法・観察時刻 | 生存等DC12案、又は時間と道具 |

## 2. 事前の情報と場所

- ベルは「湖のほとりに、たくさん咲いているそうなんです。何輪か持ち帰っていただけると嬉しいです！」と伝聞を述べる（台詞候補）。花便りのため一輪では通常不足、厳密な個数ノルマなし。現況・正確な位置・開花条件は知らない。
- タッカーも群生地・道筋の現況を買い付ける。採集と別取引。
- 伽藍の塔を訪問したPCだけ、開花標本（乳白色の五弁・淡金色中心）、同じ場所で花が見つかる報告と見つからない報告、地上の開花失敗記録を知る。既知の事実の想起は判定不要。塔は月光条件を知らない。
- 仮ID A：最初の若齢一輪。B：平たい岩を目印に初回探索できる閉蕾の場所。C：少し先の採集可能な若齢群。A/B/Cは近い岸の見通せる範囲、Bを同じ場所と識別できる形状、Cで必要量を採れる配置とする。実地形・距離・照射域・映画P0/S1との整合は未確定。PCが実際にBを調べた時だけ「先ほどなかった」と伝える。S1成熟群落は通常の採集群と区別し、ここで一斉開花させない。
- 最初の一輪は通常到着時に既に開いている案を採用候補とする。湖全体で厳密に一輪だけとは言わない。早着なら閉蕾からの開花、遅着なら既開花が複数でもよい。開花後は光が去っても直ちに閉じない。

## 3. 卓用台本（以下は読み上げ例。観察可能な情報だけ使用）

### 01 到着／解放

投影L0（湖全景）。紙地図には入口と見える岸のみ。

> 狭い岩の間を抜けると、足音の響き方が変わります。目の前には、暗がりの奥まで続く静かな湖。天井の高い裂け目から淡い月光が差し、水面がかすかに揺れています。岸辺には背の低い灰褐色の草がところどころ生えています。今ここから見える範囲に、探していた白い花は見当たりません。

数秒置いて「さて、どうしますか？」。景色を堪能する時間。疲れ・休息・会話は自由、演技を要求しない。暗視だけで色が分かるとはしない。明かりや視認可能な位置を確認する。

### 02 最初の一輪／小さな達成

岸を探す、近場を調べる等の十分な探索でAを発見。投影L1（近景）。成功判定不要。

> 水際の岩のそばに、淡く照らされた小さな白い花が一輪あります。薄い花弁は五枚。中心は淡い金色で、細い青緑の葉が足元に伸びています。

「ベルから聞いた白い花の特徴に合います」。塔の標本を見たPCには一致を伝える。摘むならそのまま採集し、所持品に「空雪花一輪」と記録。最初の株を採っても後の推理を妨げないよう、採集地点の光景と葉の形を記憶/記録できる。採集は強制しない。

### 03 足りない／違和感

他の花を探すなら、Bの目印と初回状態を伝え、紙地図の地点を必要に応じ示す。

> 平たい岩の向こう側にも草がまとまって生えています。ここはまだ薄暗く、白い花は見当たりません。

「群生しているはずでは？」とPLが言うのを待つ。言わなければ必要時のみ「ベルは、湖のほとりにたくさん咲いていると話していましたね」。原因を代弁しない。
草を近くで調べる：
> 茎は枯れておらず、青緑色の葉は、先ほど見つけた白い花によく似ています。灰褐色の先端は下を向いて閉じています。どうやら蕾のようです。

比較できれば基本事実は判定なし。まだ似ているだけで種が確定しない場合、自然DC10で観察できる萼の隙間・花弁候補を返せるが、本編の見せ場を次の場面に集中し、不要なら省く。

### 04 二輪目／世界が変化する

Bが実際に開花した時刻以降、PCがBを再び見られる時に投影L2（Bの同構図の変化）。
> 先ほど調べた平たい岩のそばに、白い花が一輪見えます。

「さっきは確かになかった」と尋ねられたら、初回観察の事実を確認する。ここで「月光で開きました」と原因を付けない。開花の瞬間を既に見ていたなら隠さない。Aを摘んでいた場合は「二輪とも今咲いている」と言わず、Aの以前の光景とBの現在の光景を比較する。

### 05 キャラクターの能力／ひらめきの機会

「何が違ったのか」「どうして今咲いたのか」という疑問に応じ、適切な方法を選んでもらう。停滞時だけ「前に見た様子を思い返したり、植物のことを考えたりできます」と提案。ダイスはD20能力値判定。各DC10は試案。全員に同じ判定を順に強制しない。別の方法なら別のPCの参加・適切な援護を認める。同じ状況の再ロールはしない。既に見抜いた事実・既知記憶は判定で奪わない。

| 宣言・技能 | 成功時の情報（実際に観察できた事実に限る） | 失敗 |
|---|---|---|
| 【知力】〈自然〉DC10／植物の開花条件を考える | 「植物の中には、光や時間帯によって花を開くものもあることを思い出します」 | 「この花の開花条件までは分かりません」 |
| 【知力】〈捜査〉DC10／AとBを比較 | 「最初の花を見つけた時、足元が淡く照らされていたのを覚えています」 | 「何が変わったのか、まだ整理できません」 |
| 【判断力】〈知覚〉DC10／周囲の細かな変化 | 「平たい岩に落ちる影の位置が、先ほどとは変わっています」 | 「細かな変化までは分かりません」 |
| 塔の資料を思い出す（訪問済み） | 「同じ場所でも花が見つからないことがある、地上栽培では開花しなかったという話でした」 | 判定不要 |

自然の知識は一般論で空雪花の真相を既知にしない。PLが「今の花も月光が当たってる？」と聞けば事実を答える。光の仮説を出したなら「まだ閉じた株が少し先にもあります」と観察対象を示す。正解発言の判定を要求しない。照射先を細かく予測する必要があれば捜査DC12案（重複しない場合のみ）。

### 06 月光で開く／検証と救済

PLが予想して観察する場合、全員失敗、ヒントは得たが推理できない場合に共通の自然現象。作中時刻を固定し、実際にPCが見られる蕾を描写する。投影L3（閉蕾と月光の縁）、L4（開花近景）。
> 岸辺の岩に落ちていた影が少しずつ移っています。やがて、月光の縁が閉じた蕾の一つに触れます。
>
> うつむいていた茎がゆっくりと起き上がります。灰褐色の萼が開き、その間から乳白色の花弁が現れます。
>
> 先ほど見つけた花と同じ、五枚の花弁です。

少し間を置く。PLが気づいたら言葉を聞き、実際に見た事実を返す。必要なら「光が届いた株が開き、その先の影の株はまだ閉じています」。一度咲いた株は直ちに閉じない。推理が停滞しても原因を口にすることを強制しない。待機なら必要な時間まで短く進める。見ていなければ開花後の白花を提示する。早期帰還を妨げない。

### 07 採集／完了と任意の成果

> さらに光が届いた岸の一角に、いくつもの白い花が開いています。

実際に必要量が採れる若齢花があることを確認して「手の届く範囲で、お便りに添える分を採れそうです」。普通の採集に判定なし。PCが選んだ量を記録（必要分、希望した余分、蕾等）。勝手にカード用を増やさない。若齢花は長持ち、発光・散布しない。S1成熟群落の開花散布は鯨の場面。
> 摘み取った花は白いままで、細い茎の先に小さな五弁を残しています。

追加調査を選ぶなら、観察済み地点を地図に記録できる（入口からの道、目印、群生範囲、観察時刻・光と花の状態）。詳細を手早く整理するなら生存/地図作成道具等DC12案。成功は実際の具体的な情報を渡す。失敗でも概略を記録、時間・道具による調査可。報酬は確認した情報の価値で別取引、判定回数で決めない。

「依頼分は確保できました。ここからどうしますか？」休む・調べる・帰るの選択。鯨の予兆は別途通常プレイで設計。帰還を封じない。鯨をここで先取りして描写しない。

## 4. DMの作中時計

下表は**机上テスト用の仮時刻**。時刻の原点S=標準到着を想定した世界時刻（実際のPC到着でリセットしない）。初開花をTとした旧案とは別にSを使う。標準例ではAの開花S−5分、Bの開花S+12分、Cの開花開始S+18分とする。実際の位置・開口・月光の幅・地形、往路所要時間、若齢株数、鯨の時刻との照合前の値であり採用未確定。

| 作中時計 | 世界の状態／通常プレイ例 |
|---|---|
| S−5分 | Aの一輪に光が届く |
| S+0分 | 標準到着。入口からは白花が目立たない |
| S+3分 | 岸を探してA発見（探索による時間例） |
| S+8分 | Bを調べる。白花なし、草・閉蕾 |
| S+12分 | Bの株が開く（探索・会話中の自然現象） |
| S+18分以降 | Cの若齢群が順に照射され開花。採集可能な量に達する |

時計は絶対時刻が決まれば置き換える。会話・短い視認はほぼ即時、近場移動や調査2〜5分、広めの探索5〜10分、詳細測量10〜20分を仮目安。並行作業は最大の所要時間を使い、4人分を加算しない。技能判定を振る行為だけで時刻を進めない。PCの待機宣言は作中の時間を飛ばして処理し、卓上で実時間を待たせない。休憩・呪文の持続や消費は通常処理。光はPCの出目で動かない。
早着・遅着で一輪目・二輪目の順番が変わってよい。全ての場面を踏ませない。到着時刻の幅と照射窓が成立するかは地形・天体位置検証の必須条件。

## 5. 想定問答（卓中に即答する）

| PCの質問・宣言 | DMの返答例／裁定 |
|---|---|
| 場所が違う？ | 「聞いていた湖の特徴と合っています。見つけた白花も説明と一致します」（観察済みなら）。全湖の断定はしない |
| 何輪必要？ | 「ベルは何輪か、お便りに添える分を頼んでいました。一輪では複数の宛先に足りません」本数を後出しで固定しない |
| 枯れ草？ | 近くで見れば生きた葉・茎・閉蕾 |
| 蕾を持ち帰る | 「摘んだ後に開くかは分かりません。ベルが欲しいのは白い花です」。塔訪問済みなら地上開花失敗記録。持ち帰りを禁止しない、実際の株を記録 |
| 蕾を手で開く | 「無理に広げると傷めるかもしれません」。方法に応じて実際の観察・損傷を裁定。自然開花とは区別 |
| 松明・通常の光魔法で照らす | 見やすくなるが開花しない。具体的な呪文効果を確認 |
| 反射した月光、株の移動 | 方法を聞く。反射月光の効果、切り取った/移植した蕾の開花は未確定。卓前に作者と裁定を決める。ここで都合よく不可と決めない |
| 月光が動いてる？ | 比較の時間があれば、岩の影・照射域の実際の差を答える。初見なら時間を置いて比べられる |
| 何か思い出せる？ | 知っていることは自動、専門的な推測は適切な技能判定 |
| 咲いた花だけ持ち帰る | 実際の採集量を尊重。少量の部分達成の精算は未決 |
| 暗い場所でも花が開いている | 既開花株は光を失っても直ちに閉じない。過去の照射を知っていれば伝える |
| 湖の向こう・水中も調べたい | 見える範囲、到達可能性、深度の不明を伝える。地形・ルールに従い裁定。必須探索にしない |
| 全員が失敗／何も思いつかない | 再ロールを連発させず、次の探索・待機を確認。実際の作中時刻の開花を視認できれば描写。必要な花を採れる |
| 採った花を保存する方法は？ | 「摘んだ後も長持ちする花だと聞いています」。普通の保護・運搬。専用道具や保存魔法は不要 |
| もう帰ろう | 帰還を認める。鯨との遭遇を強制しない。報告は実際の観察に限る |

## 6. 演出・制作要件

環境音（任意）：洞窟の足音の残響から水滴と静かな水面へ。曲や環境音が必要条件にはならない。鯨の兆候と誤読される大きな水音・謎の光は新規に加えない。
投影の最低構成：L0湖全景、L1一輪の近景（周囲の葉・岩・光）、L2 Bの閉蕾と同一構図の開花後（前後2状態）、L3蕾に光が届く前、L4開花近景（L2と共用可）。全景の照射差分は必要な場合だけ。FL-01の造形に従い、花自体は光らせない。画像だけで色や小花の変化を拾わせず口頭でも伝える。文字・矢印・原因のラベルは置かない。必要な絵を選べるローカル資料、映像と地形を照合して制作。現段階で新規画像・地図の制作なし。
紙地図：入口、岸、見える目印を表示。発見した花・観察時刻・群生の記録は任意。DM用全体図ではA/B/Cの位置・時刻・S1への照射の別を持つ。未踏や鯨の情報をPL版に載せない。

## 7. 桜井式レビューと机上テスト

- 到達と一輪の発見を早い報酬にする。群生の伝聞と一輪の不足が動機、二輪目の再発見が次の喜び。発想が難しい「蕾を咲かせよう」は必須にしない。
- 予測して当たることを判定成功の報酬にする。失敗は情報が少ないという差に留め、時間を罰として浪費させない。ここは戦闘後の解放と理解の場面なので大きな危険を追加しない。追加調査で実用的な地図・買付情報が得られる。
- 通常ケース：A発見3分、B調査8分、比較12分、C開花18分以降→採集。早期推理なら比較判定を省略。全判定失敗・推理停滞でも同じC開花を目撃できる。蕾を持ち帰る宣言でも梱包・調査中に時刻が来れば開花に気づける。早期退去なら部分達成。遅着なら既開花株をそのまま採集。4人同時作業は時間合算しない。既開花株を摘んでも場所の記憶で比較可。全て机上ケースで実卓テストではない。
- 成功の指標：誰かが「さっきはなかった」「光が関係するのでは」と自発的に言える機会があること、又は自然開花の驚きから採集に進めること。正解発言率をクリア率と同一視しない。
