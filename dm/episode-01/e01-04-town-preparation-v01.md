## 3. 読み上げ台本（太字は動作、会話は例。PCが話せば中断）
### 3.1 モグラの寝床
> 年の瀬のモグラの寝床。帰省支度をした旅人、一年の冒険を語る者たち、荷物をまとめる商人。壁のチクタク掲示板から、狐人の男が依頼票を一枚ずつ外しています。
**PCへ：**「あなたは今、この店で何をしていますか？」各人20〜30秒程度、面識や来歴を決めつけない。長い自己紹介は食事や会話の中で自由に。
> タッカー「さて。今年の仕事も、これでおしまいかな」
> ベル「待って、待ってください！ まだ一件あるんです！」
> タッカー「おや、ベル。残念だが、今年はもうおしまいだよ」
> ベル「えっ！？ ……どうしましょう。今からじゃ、誰にお願いすれば……」
**ここで止める。** PCの反応を聞く。声をかけたらベルが応じる。誰も関わらなければタッカー「おや、あんたら。仕事を探しているのかい？ ちょっと話を聞いてみないか」。ベルも別のPCへ「よかったら、皆さんも！」と同じ卓へ誘う。既に同行者なら一緒に誘う。全員の発言・参加意思を尊重。
### 3.2 依頼
> ベル「私、毎年、お花を添えた年始のお便りを届けているんです。今年はその方がお花を採りに行けないそうで……。私が勝手にお手伝いしようと思ったんです！ 空雪花という花で、地下の湖のほとりにたくさん咲いているそうです」
> ベル「花便りに使えるくらい、持ち帰っていただけませんか？ 私から金貨十枚お支払いします。少ししか採れなくても、使えるお花なら五枚です！」
> タッカー「十枚か。四人で地下へ潜るには少々厳しいねえ。……空雪花の湖なら、俺にも買いたい情報がある。最近、道が少し変わったという話を聞いていてね」
> タッカー「道の現況なら十枚、次の人が迷わず行けるくらい詳しければ二十枚。花の生えている場所は二十枚、採れる場所や条件まで分かれば四十枚出そう。何か珍しいものを見つけたら、その話も買うよ。全部で四人分。もちろん、引き受ける仕事は選んで構わない」
**PCへ：**「どうしますか？ 何を知りたいですか？」追加買付・金銭の分配・独自目的を相談。タッカーは追加利益を作るのであってベルの財布を肩代わりしない。地図と依頼メモを卓へ出す。任意の情報は興味に応じ一つずつ。鯨・開花の答え・余り花のカードは伏せる。
- 金銭以外の興味：研究なら塔の標本と不一致の記録、探索なら古い道の現況を自分の地図に書き込む、薬草なら「空雪花は暗い所で目が利く薬の材料にもなるそうだ。今は年末市場に完成品がない。余分を採るなら調合を相談できるかもしれない」（#59方向性了承、具体薬効・価格・製法は未承認。約束・即納なし）。装備払いは希望時のみ買付額内で合意する提案、二重払いなし。人助けならベルの花便りそのもの。名誉・人脈は成果の任意報告や紹介を相談、階級・特権の確約なし。これらを一斉列挙しない。
- 依頼人はベル自身、本人に頼まれたわけでも約束したわけでもない。元冒険者は通常帰還後のみ対面。タッカーは同行せず帰還時の演技もなし。

## 5. 自由準備（必要なものだけ）
DM「道はこの辺りです。花について調べる、地図を手に入れる、装備を買う、そのまま出発する。ほかにしたいことはありますか？」選択肢は例で全員に一件を要求しない。各自の希望を同時に募り、一人の処理は1〜2分を目安。既に必要なものを持っているなら何もしなくてよい。街での移動描写は1文、独立シーンは希望者だけ。合流を当然視せずPLに確認。

### 装備早見
2024 Basic Rules Equipment、03の価格。火明かりは魔法・種族能力・既存装備を優先。例：たいまつ1CP/本、油1SP、保存食5SP/人日、ロープ1GP、ひっかけ鉤2GP、治療用具5GP、覆い付きランタン5GP、登攀用具25GP、治癒のポーション50GP。必要な購入だけ。治療用具は通常のHP回復品ではない。今回必須のロープ・登攀用具・ポーションは設定しない。01戦闘バランス調整後にタッカー支給品を別途確認。買った物を記録し二重徴収しない。
### 伽藍の塔：資料閲覧と後払い契約
作者合意：先に知識を提供し、後で観測記録等を受け取る契約を設ける。未履行者は次回の信用利用を断られる。以下は今回の実装案（名称・額・受付形態・清算・制限範囲は作者確認待ち）。一般公開文献は無料案、専門資料・標本は有料または後払い。研究者は問い合わせ係ではない。
> 受付「空雪花の採集記録ですね。閲覧料は金貨五枚です。これから採集に向かわれるのでしたら、帰還後の観測報告を対価にすることもできますが」
**PCへ：** 支払う、報告を約束する、調べず出発する、を選ぶ。今回は一組の資料・同じ卓の閲覧に5GP（作者合意）、契約は同意した代表者の名義で一件。仲間全員の連帯責任を勝手に設定しない。
> 受付「こちらにお名前を。花が見つからなかった場合も、その旨をご報告ください。前の契約が残っている方には、新しい契約はお出しできませんので。お忘れなく」
受付が名義・提供物・期限を記帳する。専門資料の閲覧室でPCが標本と記録を調べる。標本は乳白色の五弁、淡金の中心、小さく長持ちする花。記録は同じ湖で群生・見つからない・一部だけ開花の三報告、地上移植で開花しなかった一例。理由は分からない。希望者が研究者へ取り次ぎを求めれば、都合と関心に応じて短く応答する。会話例：
> 研究員「これから採りに行くんですか？ でしたら、花だけでなく周囲の様子も覚えておいてください」
**PCへ：**「気になったことはありますか？」仮説を尊重し、現地で見比べられる簡単なメモを渡す。標本の正確な閉蕾・光の条件・散布・鯨は研究者も未確認。塔に行かずともベルの情報で探索可能。
契約処理：帰還後の報告（場所、環境、見つけた／見つからなかった事実。実見した範囲で十分、花や鯨の発見・標本の提出を必須にしない）。口頭報告を受付が記録してもよい。履行に新たな報酬は出さない。タッカーの独立した買付・ベルの贈り物と両立し、排他契約にしない。帰還場面の感情的な結末を遮らず、希望なら後日報告を短く処理。未履行は契約者の次回の信用閲覧・新規研究協力契約を断る（一般公開資料・通常の現金閲覧まで禁止しない案）。正直な報告、または合意した閲覧料の清算で回復。帰還不能・事情説明・期限延長は受付と相談し、未発見や撤退を罰しない。新規技能ロール・信用点・会員制度・罰金は追加しない。
DM記録：契約名義／対価／期限（帰還後、具体日数は未決）／未履行・履行済・延期合意。契約しなかった者に義務を課さない。次回の冒険へ引き継ぐ。

## 7. HOME / GATE
準備を終えたPCへ「出発の前に他にやっておきたいことは？」所持図・光源・回復・食料等の実際の所持を記録。隊列は洞窟で改めて変更可。
> 地上から大昇降機HOMEに乗り、岩壁と人工の構造物に囲まれた地下へ下りていきます。そこは広大なターミナル。上層にはPORT、探索者たちが歩いて向かう先にGATEがあります。
> GATEの向こうに街道が二手に伸びています。地図の起点です。どの道へ進みますか？
料金は会員0、非会員初回1GP/人（03採用・未マージ）、既利用権は再徴収なし、復路は今回再徴収しない。地図を持つことと無料利用は別。手持ち不足は仲間の費用分担、ベルの報酬前渡し（補助案・失敗時扱いを合意）等を相談し、無理な加入を強制しない。PORTは通過必須ではない。停止階・具体的移動距離や設備は未確定なので断定せずシーンカット。光景は現地描写、地図に光源を描き足さない。R3を選んだら05へ。違う道を選ぶなら何を目指すか聞いて地図と危険・時間を示す。未設計AREAに入ることを強制しないがDM都合で禁止もしない。

| 何輪？ | 花便りに使えるくらい、具体本数固定なし。少量5、十分10、なし0。余剰の取得は本人たちの判断 |
| 10GPじゃ安い | タッカーが同じ遠征の追加買付を提示。低額でも行くなら尊重、交渉可 |
| 花以外だけやりたい | 買付を独立させる。花担当と同じ旅で協力できるか相談 |
| 道が変わっていない | それも現況確認。詳細なら上位額。安全な撤退の情報にも価値 |

| 地図院全員加入？ | 一枚を共同利用、会員資格は個人。登録は任意 |
| 地元民なので所持している | 背景で自然なら判定なしで認める。不明時の所持ダイスは旧試案であり今回必須にしない |
| 図に湖がない／この池？ | リューネ池ではない。横道の先は未確認、図の外を現地で記録する |
| 塔に行かないと失敗？ | いいえ。調べれば観察の視点が得られる。行かなくても探索で発見できる |
| 塔の契約を忘れた／花が見つからなかった | 未発見も正直に報告すれば履行。未報告の名義人は次の信用契約を断られる。清算後は再利用可（具体運用案） |
| 光が条件では？ | 「興味深いですね。今の記録では確認できません」。正しい仮説を否定しない |
| 月視薬を買う | 年末市場に完成品なし。余剰花の持込・後日調合は相談可、具体効果・価格は未承認 |
| 暗視があるから光源不要？ | 各能力と2024ルールによる。暗視の範囲外や色・薄暗さの制約に注意、購入強制なし |
| 全員準備なしで出発 | 地図案内と実際の装備、費用だけ確認。即出発 |
| 別の道へ行く | 目標・地図上の選択・作中時間を確認。戻る/寄り道/別目的を選べる。湖を移動させない |
| 誰も依頼を受けない | 参加動機を聞く。報酬・別目的の協力も拒否なら卓外で相談し強制しない |

## 9. プレイヤーに渡す短いメモ（別紙化・DM専用情報を写さない）
「今年も、あの花を」／ベル：地下の湖畔の空雪花の生花を花便りに使える程度持ち帰る。十分10GP、少量で使える花5GP、なし0。／タッカー（任意）：道の現況10GP・再訪できる詳細20GP。花の位置・分布20GP・採集できる場所や条件まで40GP。その他の珍しい情報は相談。各取引は一行全体、上位額は下位額を含み、独立。／行き方：HOME→GATE→R3→R65→地図上の横道を確認→未整備の先を調査。地図にない先は見たことだけ書き込む。／希望する準備・買付に印をつける。詳細な報酬の正本は03。
