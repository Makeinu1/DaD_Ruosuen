# 第一話・年渡の鯨との遭遇 v0.3

> 2026-11-26 DM用試案。作者承認済みの「依頼達成後の通常プレイ」「鯨は基本的にPCに構わない」「70秒全編を上映」「PCの行動結果を無効化しない」を維持。以下の具体的な進行、判定、上映接続、時刻は未承認。鯨の生態、世界設定、映画を変更しない。

## 1. コンセプト

依頼の達成は一度完了している。鯨は第二の攻略目標でも倒すべき敵でもない。知らない巨大な存在に対して、見る、備える、逃げる、調べる、働きかけるという自由がある。緊張から安全を感じる解放、さらに光と花の法則が想像を超えた規模で現れる驚異へ。花採集の観察と映画の開花がつながることを報酬とする。鯨を見たパーティーへの翌年の幸運は既存の決定。ここで名前、幸運、目的、来歴を解説しない。帰還後の意味づけは別工程。

## 2. 出現と時刻

採集終了時「依頼の分は確保できました。ここからどうしますか？」と自由行動を聞き、達成感の間を置く。通常なら梱包・記録・休息・帰路へ向かう頃に水面の変化が見える設計を目指す。鯨はPCの採集成功・ダイス・所持数で召喚されない。湖探索v1.0のS+18分以降の採集群開花に続く世界時刻Wを仮置きする候補。具体的なW・水面位置・動線・入口からの視界は地形と時間の検証後に決める。時刻をPC到着に合わせてリセットしない。早期撤収・遅着で見られない、部分目撃の可能性を残す。通常のプレイで採集を妨げないように設計し、鯨が先に出た場合も結果を優先。Wが来ていないなら帰還を阻止しない。

## 3. 卓用の進行（実際に視認・聴取できる範囲に限る）

| 段階 | DMの描写 | PCに返す問い |
|---|---|---|
| 0 達成 | 花を確保し、静かな湖。自由に調査・休憩・帰路の準備 | 「ここからどうしますか？」 |
| 1 異変（R01/R02/R04相当） | 「静かだった水面に、波紋が広がります。月光の届く水の下を、大きな黒い影が横切りました」 | 「どうしますか？」 |
| 2 浮上（R05） | 「水面が大きく盛り上がります。そこから、巨大な生き物の頭が現れます。水がその体を流れ落ちます。どうやら、鯨のようです」 | 「何をしますか？」（必要なら） |
| 3 接近（R06〜R07の前半） | 「その巨体は水面から離れ、まるで水の中を泳ぐように、岸の方へ近づいてきます」 | 「このままだと近くを通りそうです。どうしますか？」 |
| 4 通過（R07〜R08） | PCの行動結果を処理後、変更がなければ「鯨は頭を持ち上げ、岸の上を通り過ぎます。水滴が落ち、鯨はそのまま月光の方へ向かいます」 | 未解決の行動・宣言がないか確認 |
| 5 映像 | 条件を満たせば既存70.5秒の全編。冒頭は前半の再提示、後半は月光・発光・開花・散布・退場 | 一時停止可 |
| 6 余韻 | 「やがて、湖は再び静かになります」実際の目撃内容を尊重 | 「何をしますか？」 |

読み上げは短い描写と自由行動で進める。通常は2〜3回の反応機会（影、接近、通過後）を目安とし、浮上と接近をまとめてもよい。PCが今できることを宣言したら必ず裁定。段階ごとに全員へ発言を強制しない。作中の短い接近時間で長時間の行動を実行したことにはしない。必要なら順序を管理する。主観的な恐怖・感動・身構える行動を指定せず、巨大さと動きで伝える。WH-01の全長24mは描写の尺度、正確な距離は地形確認後。

## 3.1 採集終了間際の異変と20秒の即応（2026-11-26作者指定）

**作者指定**：採集を終えようとしたタイミングで異変が起こり、鯨が出現する。映像冒頭の一輪の空雪花との接続を意識する。プレイヤーは長い相談ではなく、とっさに行動を決めるための20秒の制限時間を用いる。以下は具体運用の試案で、本節を通常の反応機会・出現タイミングの優先案とする。

- 採集必要量をほぼ確保し、最後の採集・梱包を終えようとしている頃に水面の異変。任意の追加調査を要求しない。通常の遭遇時刻Wはこの時間帯と重なるよう地形・月光の時刻を調整する。生態上、採集が鯨を召喚するという因果は追加しない。PCが早着/遅着、先に帰る等の場合は実際の行動を尊重する。
- 映像R02のP0は採集群の一輪とは別の個体として残っている標準案。PCの観測可能な岸に未採集の花が残っていても自然な配置を検討する。「最後の一輪は摘めない」と強制しない。採り尽くした場合は上映との差分を処理する。花を勝手に生やさない。
- DM台詞候補：「皆さんが花の採集を終えようとしている、その時です。静かだった水面が大きく揺れます。水の下を黒い影が横切り、巨大な頭が水面から現れます。水を落としながら、その体が空中へ浮かび上がり、こちらへ近づいてきます」。実際に鯨の形が見えたら鯨のようだと伝える。距離・方向・退路・視界はPCの実際の位置に即して短く答える。
- **20秒は実卓の行動決定時間**。DMが必要な情景・選択可能な位置関係を描写した後、「今から20秒。各自、とっさに何をするか決めてください。ダイスはまだ振りません」と告げ、一斉に計測を開始する。決まった人から短く宣言（または各自一言メモ）し、全員決まれば早く切り上げてもよい。10秒残し等の合図は任意。ルール確認・理解のための質問があれば時間を止める。20秒で呪文の細部・ルール処理を終えることは要求しない。
- 即応の例：その場で見守る、身を低くする、横や後方に退く、盾や武器を構える、仲間をかばう、花を守る、攻撃・呪文を試みる。選択肢の強制やメニュー化は不要。20秒以内に宣言できない人には「その場で様子を見る」等の簡単な行動を確認する。未宣言を罰・硬直・強制失敗として扱わない。必要な配慮は個別に行う。宣言後に行動が不可能だと判明したら可能な意図の代替を確認。
- 20秒はD&Dのラウンド長や移動可能距離を変更しない。時間制限後に通常の射程・行動・必要な判定を処理。順序が重要ならイニシアチブを含む通常ルールで解決し、採用済みのPC自由行動の原則を維持。宣言のみで攻撃したことにはしない。鯨の行動に影響がなければ頭上通過、影響があればその結果を尊重。全員の結果確定後に全編上映へ接続する。
- 桜井式評価：行動決定の短さで未知への緊張を体験させ、危険を察知して備える・静観するという自分の意思を残す。時間制限は操作の複雑さやペナルティでなく即応感のため。20秒が実際のPLに適するか、DMの説明時間・判定処理時間・映画との接続は未テスト。鯨のD&D裁定表、照射と出現の時刻、映像P0の位置は引き続き未確定。

## 4. 判定と想定問答

目に見える巨大な影、浮上、飛行、通過、開花は判定不要。強制恐怖セーヴやイニシアチブは通常の観察のみなら不要。能動的に詳細な情報を得る/危険を伴う行動で、結果に意味のある不確実性があるときだけ判定する。

| PLの行動 | DMの返答・裁定 |
|---|---|
| 影は何？ | 「この段階では形までは分かりません」。水中を注視するなら知覚DC10案で見える範囲の輪郭や進行方向を把握。失敗しても浮上は見える |
| 大きさは？ | 浮上・全身を視認できれば「建物ほどの大きさ。全長20mを超えそうです」等。観察位置で変わる |
| 何の生物？ | 「鯨に似た形です」。自然DC12案で尾・胸びれの動き等、観察事実から鯨に似た生物と判断。名前・来歴・幸運・発光条件は未確認の知識として断定しない。既知の伝承があるPCは別途確認 |
| 襲ってくる？ | 「こちらの方向へ近づいています。今のところ、噛みつくような動きや威嚇は見えません」。未来の安全は保証しない |
| 岸から離れる・隠れる | 行動を処理。実際の移動先・視界に従う。追いかけたり元の位置に戻したりしない |
| 武器を構える・仲間を守る | 宣言・具体的な行動を処理。武器を構えただけで攻撃したことにしない |
| 触れたい・乗りたい | 現在位置、距離、高さ、移動速度から可否と危険を伝える。届かないなら物理的に届かない。届く方法を考案したら通常裁定。自動成功も強制失敗もさせない |
| 話しかける・意思疎通の魔法 | 呪文の実際の効果と対象条件に従う。通常の呼びかけに反応する保証なし。知性・生物分類の設定は未決 |
| 攻撃する・拘束する | 射程・視線・対象条件・判定・効果を通常処理する。鯨は巨大だから無敵という裁定は禁止。影響がなければそのまま泳ぐ。影響があれば世界の変化を反映 |
| 花吹雪を捕まえる | 実際に届く範囲なら行動を処理。離脱した花弁と小果実の状態はFL-01、持ち帰り・微光の持続・情報価値は未決。価値を勝手に確定しない |
| 記録したい | 見た姿、位置、行動、花の変化を記録。詳細調査の精度に不確実性がある場合だけ判定。目撃・報告自体は技能判定不要 |
| 何もせず見守る | 有効な選択。見えたものを描写し、判定を足さない |

**未解決の裁定**：鯨のD&D用分類、AC・HP・セーヴ・速度・効果耐性、接触時の危険、攻撃や有効な魔法への反応は現資料から確定できない。攻撃/干渉が成立する場合に備え、卓前に最低限の裁定表を作る。ステータスが未設定であることは無効化の理由ではない。DCも案。実卓未検証。

## 4.1 即応・距離・干渉の暫定裁定表 v0.3（2026-11-26試案・本節優先）

### 20秒を一度だけ使う
影→浮上→空中から接近までを短い一続きの描写にまとめる（途中の質問・行動宣言を無視しない）。危険な接近の瞬間にのみ20秒を使用。距離・方向・退路・遮蔽・PC位置など選択に必要な事実を先に示す。宣言は一言の意図でよい。「今から20秒計ります。各自、とっさに何をするか決めてください。ダイスは後で振ります」。同時に考え、決まった人から宣言か一言メモ。全員決まったら終了。時間切れなら簡単な行動（見守る/退く等）を確認し、硬直・不利・ダメージ等を課さない。ルール説明や合理的な情報確認には時計を止める。イニシアチブ前の意図表明であり、宣言した攻撃や移動が全員同時に成立するわけではない。状況が変化した場合は通常のターン中の選択を認め、20秒の宣言でPCを拘束しない。タイマーは手元のスマホ等でよい。上映用プロジェクターの画面をタイマーに変える必要なし。

### 距離の暫定値（目視の概算、実地形・映画モデルとの照合前）
全長24m（約80ft）のWH-01を維持。接近時に、岸側の最も近いPCから吻先までおおよそ60ft（約18m、卓上描写「20mほど」）を候補。現在の高さ・移動可能な退路・遮蔽物は紙地図に従う。R07の頭部とPCの目の最短約6m（約20ft）、頭上通過の約14m（約45ft）、尾先の最短約3.6m（約12ft）は既存の撮影用仮値で、全PCの当たり判定ではない。PCの移動、身長、岩棚、高さ、攻撃対象部位で射程は変わる。概略図はPC/水際/退路/鯨の進行方向と距離だけで十分。通常5ft・10ftの近接攻撃は標準位置で届かない見込みだが、移動・長い間合い・飛行・射撃・呪文は実際の射程と視線で裁定。巨大な生物の占有空間（戦闘ルール）と80ftの全長を混同せず、必要時は地形と巨体の位置を簡略に描く。鯨に近接するための方法が有効なら認める。通常軌道では接触なし、水滴のみでダメージ/セーヴなし。予定外の接触・衝突は別途裁定。映画尺をラウンド・速度に直結させない。

目的は攻撃・妨害が実際に成功/失敗することを裁定するため。ボス戦を用意することではない。既存WH-01の24mと空中遊泳以外は今回の暫定値。4人Lv2のPCの実キャラシート未確認。CR・XP・攻撃アクションを持つ本格戦闘データではない。

| AC／HP | 13／210（固定値） |

ホバリングは空中を水中のように泳ぐ表現に対応する暫定ルール。飛行不能・速度・状態異常の結果は2024ルールと個別効果の記載に従い、全ての落下を防ぐと独自に断定しない。Beast分類なら動物を対象とする呪文等が適用可能な場合がある。効果を恐れて後から種別・耐性を変えない。巨大だから自動ミス・ダメージ0とはしない。HP0等の重大な結果が起きたら通常のルールを適用し映像のために回復させない。敵対が長引く場合の行動、接触事故、詳細ステータス、XPは未整備で別途決める。

### 行動別の処理例

| 宣言 | 処理 |
|---|---|
| 身を低くする、盾を構える、花を守る | 具体的な行動を認める。鯨が通過するだけなら判定不要 |
| 岩陰へ退く、仲間を連れて退く | 移動距離と通行可否を確認。争いがなければ通常の移動。時間が重要ならターン順 |
| 見守る | 基本の目撃情報は全員に。観察内容を記録することは可 |
| 生態を詳しく知りたい | 状況が許す場合だけ自然DC12案。外見・泳ぎ方などを具体的に返す。飛ぶことや白鯨の姿そのものを判定で隠さない |
| 弓で射る | イニシアチブ等で順番を管理し、ターンで射程・視線・攻撃ロール対AC13。命中ならダメージをHPから減算。通常の遊泳に影響する効果がなければ鯨は通り過ぎる |
| 近接攻撃 | 射程外ならその位置では届かないと宣言前/裁定時に伝える。移動、待機（Ready）など合法な代替を認める。条件に合う機会攻撃のみ通常処理 |
| 呪文で止める・意思疎通 | 呪文の射程、対象種別・サイズ、セーヴ、効果を確認。成功した効果を反映。声をかけるだけでは反応保証なし |
| 鯨に触る・乗る | 距離・高さと方法から可否を決める。普通に手を伸ばすだけでは標準離隔で届かない。届く手段を考案すれば通常裁定。騎乗の条件は別途確認 |

敵対的行動がある場合、DMが戦闘開始を判断して全員と鯨のイニシアチブを振る。2024 DM's Toolboxの戦闘開始行動者への有利は適用可能な任意裁定、今回は自動付与しない案。鯨のターンには移動し、必要ならDash（速度追加）。鯨が射程外へ移動したなら後のPCは通常どおり行動を変更可能。20秒の宣言順を戦闘順にしない。行動・移動・リアクション・呪文の結果を処理してから上映判断。判定のため映画の後半を先に説明しない。

### 机上ケース
1. 四人が観察・防御：20秒→判定なし→通過→上映。
2. 弓で攻撃：イニシアチブ、射程内のターンで命中/失敗処理（例：AC13に攻撃合計16、ダメージ8ならHP202）。実質的な進路変更がないなら遊泳続行、傷の描写と映像の差は実プレイ優先。
3. 剣で攻撃：標準位置では離隔がある。射程内に移動できないなら代替、勝手に攻撃成功/空振りにしない。
4. 減速・拘束に成功：移動や状態変化を適用し、通過時刻・場所が変われば通常映像を事実として上映しない。上映例外は作者確認。
5. 一人が退避して見えない：目撃の有無を記録。PCが強制的に岸にいる映像扱いにしない。
6. 時間切れ：本人の簡単な選択を確認し、結果に不利を課さない。
実際の卓では未検証。攻撃を選ばなければ数分で終える。PLの不安を誘う情報は事実（巨体・進行方向）に限定し、「攻撃しようとしている」とは誤認させない。

## 5. 上映の切替

推奨ポイントは鯨が頭上を通り過ぎ、月光の方へ向かう直後（R08相当）。PCが「どうするか」を選べた後であり、後半の発光・S1一斉開花は初めて見ることができる。台詞候補：「鯨は、そのまま月光の方へ向かっていきます」。卓外に「ここからは、この光景を映像でも見てもらいます。前半は今の出来事の再現です」と短く説明する案。暗転→全編上映→少し間→「湖は再び静かになります。どうしますか？」。映画の冒頭を飛ばさない。70秒は実卓の上映尺であり、作中時間の正確な経過秒数に固定しない。鯨が光ること・花雪の全貌は上映前に口頭で先取りしない。

通常上映の条件：全員の直前の行動と結果を処理済みで、PCが観察を続けられる位置・状況、鯨が予定どおり進める状態。全編を非インタラクティブに固定するのではなく、希望があれば停止し宣言を裁定する。中断後も矛盾しなければ続ける。PCが鯨に実質的な影響を与えた、離脱した、一部しか観測できない場合は卓上の結果を優先し、全編を事実として見せない。矛盾が大きい場合は口頭描写に切り替え、上映を見送る（例外案、作者確認前）。映画は通常遭遇を彩るためのもので、別の世界線を確定しない。
現行v14.9bはR06で4人が身構え一人が下がる、R17bで4人が見送る。これはPCの行動を固定する危険がある。通常上映でもシルエットの身振りはイメージとして説明し、実際の行動が優先。離脱や位置差が大きい場合の映像利用は検討が必要。P0は採集株と同一と固定しない。現行絵コンテの修正・追加映像制作は今回行わない。上映素材の最終品質は別途監督・制作検証。

## 6. 桜井式レビュー・机上ケース

ご褒美を新たな戦闘の勝利にせず、自由に反応した結果と驚異の光景に置く。接近の緊張と無害な通過による解放、既に知った花の法則が大きな現象へつながる。ダイスは観察を豊かにし、見る権利を決めない。通常の卓上遭遇は5〜10分目安＋全編上映70.5秒案、長時間の反復問答を避ける。強制恐怖・謎解きの追加・露骨な報酬条件なし。
机上ケース：観察（通常上映）、警戒して後退（視界・位置が合う限り上映）、攻撃を宣言（効果・順序の処理後に判断、裁定表未準備）、成功した拘束等（結果を優先し通常上映見送り）、早期撤収（見なければ目撃報酬なし、依頼達成は維持）、一部のPCが別行動（個々の目撃を記録し幸運の対象範囲は未決）。実卓のテストではない。最大の未解決事項は鯨の裁定表、照射時計との出現時刻・地形、PC行動とシルエットの差分、上映の例外・停止運用、持ち帰る散布体の裁定、帰還後の説明。
