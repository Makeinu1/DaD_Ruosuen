# ベルとタッカー — DM用演技ガイド・掛け合い集

> プレイヤー閲覧禁止／SPOILER WARNING: DM only. 第一話の依頼に触れる台詞を含む。
> 2026-11-20 作者承認：演技例を保存する。以下はロールプレイの参考であり、固定台本、発生が確定した事件、世界設定の追加ではない。

人物の正本：[ベル](../../world/npcs/bell.md)／[タッカー](../../world/npcs/tucker.md)。二人の共通の志は「つなぐこと」。ベルは個人の事情を、タッカーは社会的な隔たりと価値を見ている。

## 口調の基本

| 項目 | ベル | タッカー |
|---|---|---|
| 一人称 | 私 | 俺 |
| 二人称 | ○○さん、皆さん | あんた、あんたら |
| 相手の呼び方 | タッカー | ベル |
| 口調 | 親しみのある敬語 | くだけた軽口、商談では丁寧な敬語 |
| 速度 | 早口、畳みかける | ゆっくり、間を取る |
| 感情 | 素直に表に出す | 冗談や皮肉に包む |
| 口癖 | 「そうだ！」「いけない！」 | 「おや」「さて」「悪くないね」 |
| 話の起点 | 相手の事情 | 結論や条件 |

ベルが感情から話を始め、タッカーが理屈で返すが、最終的に同じ方向を見ている。単なるボケとツッコミにしない。

## Scene 1｜冒険者との初対面

ベルは相手のことを知りたがり、タッカーは相手に何ができるのかを知りたがる。

**ベル：**「ようこそルオスエンへ！　皆さん、どちらからいらしたんですか？」

**タッカー：**「ベル、尋ねる順番が違う。まずは仕事を探しているのかどうかだ」

**ベル：**「もう！　せっかく遠くから来てくださったんですよ？」

**タッカー：**「なら、なおさら金が必要だろう？」

**ベル：**「……それは、そうですけど」

**タッカー：**「さて、ご一行。何が得意だい？」

## Scene 2｜二人の時計

二人が同時に時計を取り出す。

**ベル：**「いけない！　もう四時です！」

**タッカー：**「おや、まだ四時か」

**ベル：**「どうしてそんなに余裕なんですか！？」

**タッカー：**「君と違って、今日できる仕事しか引き受けていないからね」

**ベル：**「だって、皆さん困ってたんですよ！」

**タッカー：**「そして今、一番困っているのは君だ」

## Scene 3｜ベルの依頼

**ベル：**「実は、あるご夫婦がどうしても欲しいお花があるそうなんです！」

**タッカー：**「花？　報酬は？」

**ベル：**「もう、お金の話ばっかり！」

**タッカー：**「俺にじゃない。こちらの冒険者諸君にだよ」

**ベル：**「あっ……聞いてきます！」

**タッカー：**「……まさか、花の名前は聞いてきたんだろうね？」

**ベル：**「それくらい覚えてます！　空雪花です！」

**タッカー：**「どんな花？」

**ベル：**「…………」

## Scene 4｜仲介料について

**ベル：**「紹介しただけでお金をいただくなんて、私にはできません！」

**タッカー：**「紹介しただけ、ねえ。相手を探して、信用を確かめて、条件を整える。立派な仕事じゃないか」

**ベル：**「でも、喜んでもらえたらそれで十分です！」

**タッカー：**「結構。俺は喜んでもらった上で、金もいただくよ」

**ベル：**「欲張り！」

**タッカー：**「商人と言ってほしいね」

## Scene 5｜タッカーの仕事

ある商人が、腕のいいゴブリンの職人を雇うことに難色を示している。

**商人：**「だが、ゴブリンの職人だぞ？」

**タッカー：**「ええ、存じておりますとも。それで、何か品質に問題でも？」

**商人：**「いや、そういうわけでは……」

**タッカー：**「では、何を迷っていらっしゃるので？」

商談を終えた後。

**ベル：**「よかったですね！　あの職人さん、本当に喜んでました！」

**タッカー：**「ああ。実にいい取引だった」

**ベル：**「タッカーも嬉しいんでしょう？」

**タッカー：**「もちろん。次の注文もいただいたからね」

タッカーは大商人には丁寧な敬語を使い、相手によって話し方を変える。この例は社会全体の偏見や制度を確定するものではない。

## Scene 6｜互いについて聞かれたとき

**冒険者：**「どうして二人は一緒に仕事をしているんだ？」

**ベル：**「私にもよく分からないんです。こんなにお金のことばかり考えてる人なのに！」

**タッカー：**「俺も不思議でね。商売人としては実に不可解な兎だ」

**冒険者：**「仲が悪いのか？」

**タッカー：**「さあね。……だが、こいつの仕事は嫌いじゃない」

**ベル：**「……私も、タッカーの仕事は好きですよ」

**タッカー：**「そりゃ光栄だ」

## Scene 7｜冒険者が無事に帰還したとき

**ベル：**「お帰りなさい！　お怪我はありませんか！？」

**タッカー：**「お疲れさま。さて、仕事の首尾は？」

**ベル：**「まずは無事に帰ってきたことを喜んでください！」

**タッカー：**「喜んでるさ。優秀な取引相手が減らずに済んだ」

**ベル：**「……もう、素直じゃないんですから」

## DM用・即興演技の早見表

| 状況 | ベル | タッカー |
|---|---|---|
| 相談された | 共感する | 条件を聞く |
| 失敗を聞いた | 心配する | 次の手を考える |
| 成功を聞いた | 一緒に喜ぶ | 相手の能力を評価する |
| 意見が対立した | 感情を率直に伝える | 皮肉を交えて反論する |
| 本当に怒った | 声を上げる | 冗談を言わなくなる |

タッカーは普段軽口を叩くからこそ、冗談が消えるときに本気だと伝わる。ベルがいつも間違い、タッカーがいつも正しいという関係にしない。タッカーが見落とした一人の気持ちをベルが見抜く場面も大切にする。

固定台詞を覚える必要はない。PCの発言と状況に応じて即興で変える。両者ともPCの冒険・戦闘には同行させない。
