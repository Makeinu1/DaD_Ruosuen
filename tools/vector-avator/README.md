必要：Git、Node.js 22、npm、Python 3.10以上、ネット接続。フル制作には別途 Codex CLI の認証、Claude Code/Fable 5.2、resvg、ffmpeg が必要。実行前に外部コード・依存ライブラリを確認すること。

```bash
python tools/vector-avator/bootstrap.py
```

```bash
cd ../vector-avator-ruosuen

```

http://localhost:5280/ で上流サンプルを確認する。別のポートを使う場合は上流の手順に従う。

## 制作手順
上流の .claude/skills/vector-avator/SKILL.md に従う。正本は [承認済み共同原画](../../world/npcs/art/README.md)、[ベル](../../world/npcs/bell.md)、[タッカー](../../world/npcs/tucker.md)。
1. ベルの正面Aポーズ、4面図、表情差分を生成・レビューする。タッカーも同様に作る。共同原画には二人がいるため混同しないこと。
2. ベルは小柄、タッカーは長身・細身という原画の対比を維持する。上流の標準2〜2.5頭身への一律変形は採用しない。
3. 各キャラの var/vector/<id>/pending-character.json を data/characters/<id>.json にコピーし、上流の部品分け工程で vector.json を生成する。Fable 5.2 にアクセスできない場合は工程未実施と記録する。
4. check_parts.py と avatar/check.py、ビューアによる目視検査を実施する。耳・尾・鞄・コートの前後関係、頭の回転、腕の接続を重点確認する。
5. 最小のモーション：待機、会話、驚き、説明、うなずき。ベルは慌ただしく、タッカーは余裕のある身振り。演技倍率は仮値。
6. 時計と帳簿は後から追加する独立した小道具。手との連動、視線、前後関係は追加実装が必要か検証する。二人の同時表示とマイク入力も別工程。
