# ルオスエン 世界設定の正本

ここは**ルオスエン世界の設定を保守する場所**です。プレイヤーに読ませたい内容は、この正本をもとに `docs/`・`players/` に編集し、GitHub Pagesのナビゲーションへ選んで載せます。

最初に[世界設定・公開運用規約](../WORLD_POLICY.md)を確認してください。

## 現行設定の入口

- [世界の骨格](01_世界の骨格.md)：創世、大転流、歴史の基本的な関係。
- [マナ・魔石・迷宮と社会](02_マナ・魔石・迷宮と社会.md)：魔石の純度と寿命、迷宮の地質と生態、文明と自由迷宮都市。
- [未決事項・移行の注意点](03_未決事項・移行.md)：まだ決まっていない事項、移行で復活させてはいけない旧案。

## 大切な区別

- **世界設定の事実**と、**作中人物が正しいと信じること**は異なる。
- **D&D卓のゲーム上の変更**と、**小説を含む世界の基本法則**は異なる。
- **採用済み**と**AIや参加者による提案**は異なる。
- **このリポジトリはPublic**であり、`world/` に置いたものはPagesの案内に載らなくても誰でも読める。未公開のネタバレは非公開保管先へ。

## 移行と版管理

2026-11-13から、**GitHubの `world/` をこれからの現在値の記録先**とします。以前の長大なNotion原稿は移行元のアーカイブ・未移行論点の確認先として残します。現時点で全項目の移行は完了していません。

旧原稿を一括転記するのではなく、論点ごとに承認状況・矛盾・公開可否を確認してから追加します。改訂した決定はGit履歴に残し、`docs/` に影響がある場合は更新します。
