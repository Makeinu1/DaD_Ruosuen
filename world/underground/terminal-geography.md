# ルオスエン・ターミナル立体地理設計 v0.4

2026-11-29 作者承認（現行案採用、Blender検証省略、main統合指示）。本書はターミナルの地理・施設構造の正本。寸法は作者が裁量を委任した設計基準値であり測量済みの数値ではない。

## 1. 都市と地形
大断裂の東西両岸に地上市街とHOMEがある。地表の裂け目より地下が大きく広がる不規則な天然空洞。ターミナルはファーストライト大空洞（AREA 1）の地上接続部にある局所活動圏であって、AREA全体や独立都市ではない。既存の数km規模のAREA輪郭を縮小しない。地上方位は地表接続の説明にだけ用い、地下携行図には方位を付けない。地下から別AREAへの距離・方角を地上から推測しない。

| 要素 | 設計基準値 |
|---|---:|
| 地上の裂け目の幅 | 約150m |
| ターミナル周辺の空洞最大幅 | 約500m |
| ターミナル周辺の南北方向の広がり（地上接続部の局所軸） | 約900m |
| 地表基準 | 0m |
| 広場層 | -150m |
| PORT層 | -200m |
| GATE層（上側乗降場） | -265m |
| 地下街道入口（NODE:GATE） | -345m |

地表基準は概念上の代表高さ。既存台帳のAREA:1/GATEを0mとする局所標高に換算すると、広場+195m、PORT+145m、GATE層+80m。既存PORTの高さと一致する。地上面の傾斜・個々の足場の高さ・HOMEの正確な座標・地上と台帳XYの変換は未決。

西からの大河の分流は大断裂へ滝となって落ちる。主要街区の北側寄り、船の航行空間およびHOMEの昇降経路と離れた位置を設計基準とする。地下水系の接続先・流量・増水時の影響は未決。地上への船の自由飛行はできない既存設定を維持。

## 2. 構造
岩壁から張り出した板状人工床版を基本とする。両岸それぞれのTREEが独立して枝を伸ばし、一部で大きく結合し、必要箇所で細い連絡橋を架ける。空洞全体を覆う床にはしない。古い足場に世代ごとの増築が重なる。中央の最大結合部は広場。

床版には上方に立ち上がる回転翼「浮羽」がある。タケコプターのように翼が上にあり、風車のような回転で魔力の流れを効率化する。支持力は浮遊魔法によるもので、空気力学的揚力・推進用プロペラ・強い吹き下ろしではない。岩壁への接続と浮遊を併用する。具体的な支持構造、翼数、回転速度、停止時挙動、魔力供給、整備周期は未決。

## 3. 施設と活動
- HOME：地上の両岸から広場層へ接続する大昇降機。東西各一基を基本配置とする。地上に乗降場、下方に人工足場との接続を設ける。台帳のFACILITY:HOMEは旧来の代表表示として保持し、個別設備の採番・座標は測量設計後に更新する。
- 広場層：両岸を大きく結合する中央広場。中央には「ROUTE ZERO」と刻まれた記念碑。待ち合わせ、乗換、積荷整理の場。記念碑の由来・建立者・年代は未決。ターミナルの旧名、現役ROUTE番号、測量原点としては使わない。
- PORT層：広場の下。両岸の桟橋へ通常は魔導船が浮いた状態で係留される。岩壁側の倉庫・船舶修理工房、荷役場と結ぶ。中央の空域と巨大な横穴を船の航路に確保する。横穴の数・正確な行先・船型・航行間隔は未決。他国PORTとの国際航路という既存設定を維持。
- GATE層：PORTのさらに下の独立した待機・通過階。中央の下行昇降機から80m下の徒歩街道入口へ至る。この層の呼称は便宜上の設計用語であり、既存のGATE（R3/R7共通端点）を上側へ移動させない。下行昇降機は地上HOMEとは別設備。GATE層の足場は両岸から中央へ接続し、下行設備に必要な範囲だけを結合する。
- 食堂、酒場、売店、補給用品店、修理工房、倉庫を中心とする。限定的な商店・出航待ちの宿泊設備は許容する。一般住宅、観光施設、娯楽施設、大規模な衣料・百貨店的商業は基本的に地上側。東京駅と連続地下街から観光的要素を除いた交通・物流・探索に特化した機能構成を参考とし、現代駅の建築意匠は模倣しない。
- 岩壁側には店舗や作業場、開放側には通路・手すり・眺望。岩盤内の短い通路も許容。ターミナルは目的地ではなく結節点。居住人口や店舗数、運賃、運行時刻は追加設定しない。

## 5. 動線
人：地上→HOME→広場→目的のPORTまたはGATE層→下行昇降機→NODE:GATE。PORTは探索者の必須立寄り先ではない。帰還は逆方向。貨物：HOME・広場の荷捌きからPORT桟橋、倉庫、修理工房へ。人流と荷役の中心通路を分け、貨物用の短絡設備は必要に応じ設計する（具体設備は未決）。船：横穴→PORT係留→横穴。地上へ船を通さない。下層から鉱石等を搬出する流れも上層へつなぐ。局所産業用軌道の既存ID・位置を変更しない。

## 6. 台帳・発行図との整合
既存NODE:GATE (2210,2000,0)、NODE:PORT (2450,1850,145)、FACILITY:HOMEの代表平面位置 (2050,1850) を維持する。TERMINALは活動圏であり代表NODEは模式接続に限る。既存HOME/PORT間の平面離隔400mを許容する局所設計。地上接続の正確なXY変換・二基のHOMEの個別位置・下行昇降機の登録は未決のため、atlas.jsonに未測量の座標・ID・REPORTを捏造しない。既存28地点、12 ROUTE、43 SEGMENT、FACILITY ID、携行図改訂03の発行内容を維持する。局所設計と台帳の精密な重ね合わせは未検証。ROUTE ZEROのROUTEレコードは作らない。

## 7. 美術共通制約
地上は冬の年末の日常。地下は作業・移動に必要な人工灯、自然光の届く範囲の対比。昼間の地上照明は必要性のある箇所に限定。年末感は荷物、帰郷・出航待ちの旅客、仕事納めの船員などで表現し、観光市場にしない。地上から見える範囲と下降中の視界開放、空洞側の眺望を使う。未確定の光量・正確なカメラ座標・船のクリアランスは描画ごとに整合を確認する。
