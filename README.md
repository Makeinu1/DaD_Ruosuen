# ルオスエン | Ruosuen

> 地上の繁栄を支えてきた魔導文明は、いま資源の転換期にある。人々は地下に広がる巨大迷宮へ向かう。そこには魔物だけでなく、交易路、水源、鉱山、未知の暮らし、そしてまだ誰も描き終えていない地図がある。

**Dungeons & Dragons 2024年版を暫定的に基本とする、4人パーティーの短編ダンジョン探索企画**です。毎回、迷宮都市で依頼を受け、1〜2回のセッションで一つの冒険を完結させます。初めて参加する人は、このページから始めてください。

## 参加にあたって

- **プレイヤー：** 4人を想定。新規参加や単発参加も可能な形式を目指しています。
- **システム：** D&D 2024年版を**暫定採用**。初期レベルは**3（提案・未確定）**。
- **一話の長さ：** 3〜4時間×1〜2回を想定（開催時間は未確定）。
- **舞台：** 五大国の地下経路が交わる自由迷宮都市と、その周囲の多様なダンジョン。
- **目的：** 毎回、救助・探索・討伐・調査など、達成可能な依頼があります。解決方法はプレイヤーに委ねられます。

キャラクター作成前に確認が必要な項目は、[決定事項と未決事項](DECISIONS.md) を見てください。

## 世界の楽しみ方

- 世界は一つの巨大迷宮を中心に広がりますが、**すべての場所が最初から説明されているわけではありません**。
- 「あの先は何だろう」と思うものが見つかったとしても、今回の依頼を完了して帰還すれば冒険は完結します。
- プレイヤーが考案した出身地、職業、習慣、噂は、DMとの相談を経て設定に取り込む余地があります。
- 原則として**秘密の真相やシナリオ本文はこのリポジトリに置きません**。ここはプレイヤー向けの共有資料庫です。
