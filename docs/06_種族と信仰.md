# 種族と信仰 — この世界に、君の生き方を

同じ街へ来ても、生まれた土地も、身につけた技も、大切にしているものも違う。君が何を信じ、誰と生きてきたかは、迷宮へ向かう理由にもつながる。

## 出身と暮らしを考える

キャラクター作成では、**D&D 2024年版の種族・クラス・背景を基本にする**ことを暫定方針としている。

種族を選んだら、その人がどこで、誰と暮らしてきたかを考えてみよう。港で荷を扱ってきたのか、工房で技を学んだのか。遠い土地から来た旅人なのか。

種族だけで出身国や職業が決まるわけではない。故郷や共同体の細部はDMと相談して作れる。既存のD&D公式世界の国や歴史を使いたいときも、レウナの中でどう表すかを一緒に考えよう。

## 身につけた力を、どう表す？

クラスは、君の人物が何をできるかを支える。その技をどこで学び、どんな仕事に使ってきたかには、さまざまな表し方がある。

| クラス | 人物像を考える手がかり |
| --- | --- |
| ファイター、バーバリアン、モンク | 鍛えた技と身体、内なるマナをどう扱うか。何のためにその力を身につけたか。 |
| ローグ、レンジャー | 人や生き物の痕跡を読み、危険な道を抜ける技を、どこで学んだか。 |
| ウィザード、ソーサラー、バード | 学問、直感、訓練。マナを扱う力とどう出会い、磨いてきたか。 |
| クレリック、パラディン、ドルイド | 信仰、誓い、自然や生命との結びつき。何を大切にして力を使うか。 |
| ウォーロック | 契約や学識、異質な力との関わり。その力に何を求めているか。 |

これらは人物像の手がかりで、クラス能力の変更ではない。契約相手や魔法の出自など、世界に関わる背景はDMと相談できる。

## 地下へ向かう信仰

ルオスエンには、迷宮の最深部を聖地とする信仰と、それを受け継ぐ**星路教会（セイロ）**がある。深奥から戻って「神を見た」と語った**最初の帰還者**を開祖とし、彼が最奥で神に会ったという伝承に基づく宗教だ。

開祖が歩んだ道は、星を巡る路という意味で星路と呼ばれる。巡礼者は星の名を持つ地下の地点を巡る。正確な地図は失われ、開祖の口伝と先人の足跡を手がかりに最奥の聖地への再到達を目指す。後の時代の弟子や聖人、巡礼者の話も重なり、信仰は人々の生活や共同体の中に根づいている。

君もその道を求める一人かもしれない。信徒の旅を助けたいのかもしれない。別の土地の信仰や思想を持ち、この街の巡礼者と出会う人物でもよい。

神々、自然、祖先、死について、人々の考えが一つに揃っているわけではない。何を信じる人物か、何をまだ迷っている人物かを考えてみよう。

## 遊び始める前に、相談しておくこと

クレリックやパラディンも選べる。ただし、神が直接語りかけ、具体的な使命を授けることを前提とする背景や能力は、この世界で成立する表現をDMと相談しよう。

蘇生、遠距離転移、他次元移動などを人物の中心に置きたい場合や、追加サプリメントの選択肢を使いたい場合も、先に確認しておきたい。世界の歴史や国のあり方を大きく決める出自も同様だ。

大切にしたい人物像を伝えて、遊べる形に整えていこう。具体的な準備は[キャラクター作成ガイド](../players/キャラクター作成ガイド.md)へ。
