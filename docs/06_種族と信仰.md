# 種族・信仰とD&Dクラスの扱い

この世界には固有の歴史がありますが、**D&D 2024年版の種族（Species）・クラス（Class）・背景（Background）を基本にキャラクターを作る**ことを暫定方針とします。世界独自の機械的な種族データはまだ定義しません。

## 種族
D&D 2024年版の基本ルールに収録される種族を出発点にできます。ただし「特定種族の帝国がある」「この種族は必ず地下生まれ」など、**出身文化や国家設定を先に決め打ちしない**でください。

提案した種族が世界にどう暮らしているかは、DMと共同で作れます。既存のD&D公式世界の歴史をそのまま移植するわけではありません。

## クラス

| D&Dのクラス像 | この世界での解釈例 | 注意 |
|---|---|---|
| ファイター、バーバリアン、モンク | 技術と内なるマナによる身体能力の発揮 | 既存のクラス特徴を原則そのまま使う |
| ローグ、レンジャー | 迷宮での偵察・追跡・地形への対応の専門家 | 罠解除や生態観察が活躍できる |
| ウィザード、ソーサラー、バード | 術式、直感、訓練などでマナを利用する術者 | 魔法の出自は相談可能 |
| クレリック、パラディン、ドルイド | 信仰、誓い、自然や生命との結びつきを通じた力の運用 | 神との直接会話を前提とする設定は調整 |
| ウォーロック | 特殊な契約や学識、異質な力の使い手 | 契約相手と力の出自をDMと協議 |

これはフレーバー上の説明で、クラスの公式能力や呪文の機能を無断で変更するものではありません。

## 神と信仰
ルオスエンには世界を形作る存在についての信仰や思想があります。一方で、神々が信徒へ直接語りかけ、毎回具体的な使命を授けるという形式は既存設定と合いません。

クレリックやパラディンのプレイは歓迎します。神託・直接交信を前提とする能力や背景は、プレイ開始前にDMと一緒に成立する表現を検討します。

## キャラクターを作るときに確認したい選択
- 他のサプリメントに含まれる種族・サブクラス・特技を使用したい。
- 蘇生、遠距離転移、他次元移動、直接の神託など、世界設定との調整が必要な呪文を主軸にしたい。
- 世界の歴史を大きく決める出自（王族、神に選ばれた者など）を設定したい。

いずれも即座に禁止するためではなく、**楽しく遊べる形で先にすり合わせるため**の相談事項です。
