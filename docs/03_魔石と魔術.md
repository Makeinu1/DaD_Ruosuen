# 魔石と魔術

## マナとは
マナは魔術と魔導技術を支える力です。照明、熱、運動、電力など、さまざまな働きに利用されます。一般の人も魔導具を通してその恩恵を受けられますが、土地によって使いやすさが異なります。

- **魔術師：** 状況に応じて術を組み立て、外のマナを利用・制御することに長ける傾向があります。
- **戦士：** 体を動かすとき、自分の内なるマナを扱って身体能力を高めることがあります。
- **魔導具：** ある機能を安定して繰り返すよう設計された道具です。

これらは世界の説明であり、D&Dの各クラスのルールを新しく置き換えるものではありません。[種族・信仰とクラス](06_種族と信仰.md)も参照してください。

## 魔石とは
魔石は、マナを保持する特殊な結晶鉱物です。工房や街の設備、携帯型の魔導具で燃料として使われ、使用すると消耗します。

魔石には**純度**の差があります。結晶の質が良く欠陥や不純物の少ない部分は高純度と呼ばれ、一般に高価です。ただし、純度の高い小粒の石が、いつでも大きな石より多くのマナを持つわけではありません。

良質な部分を見極めて切り出し、傷つけずに加工する職人技が必要です。研磨や精錬で無からマナが増えるわけではありません。

## 魔石の採掘と保管
優良な魔石鉱床が成熟するには、非常に長い年月が必要です。地質の古さ、鉱物の条件、周囲の環境などが関わるため、**深いほど必ず良い魔石があるわけではありません**。

魔石は場所によって保存のしやすさが違います。周囲のエーテル環境が乏しい地域では、時間が経つにつれてマナが失われることがあります。採掘した瞬間に劣化するわけではなく、環境と時間が大切です。

エーテルそのものは人間に直接知覚・操作できず、魔石や地形などの変化から間接的に推定します。魔石の劣化速度や性能の細かな数値は、まだゲーム用に決めていません。

## レイライン
レイラインは、魂の帰還とも結びつけて語られる、世界の目に見えない流れです。学者や測量士は魔石、地層、環境の変化などから間接的に手掛かりを探します。

**通常の探知魔法でレイラインを直接見る、思い通りに動かす、封鎖する、といったことはできません。**

## 死と回復
傷や病の治療に魔術が役立つことはあります。しかし、命を失い魂が離れた人を元の個人として呼び戻すことはできない、というのがこの世界の基本原則です。

D&DのHP回復や死亡セーヴなどの一般的な戦闘ルールをすべて書き換えるわけではありません。**蘇生系呪文の使用可否・置換方法は、プレイ開始前にDMと確認してください。**
