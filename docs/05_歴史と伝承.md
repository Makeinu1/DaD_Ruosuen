# 歴史と伝承 — 誰もすべてを知ってはいない

この文書は**プレイヤーが作中で耳にする知識**です。確かな歴史、学者の仮説、酒場の噂は同じではありません。

## 広く認められている出来事
- 地上では以前、いまより豊富なマナが生活・産業に使われていました。
- 大規模な地殻の変化と資源供給の変化が重なり、多くの土地で従来の暮らしが難しくなりました。
- 迷宮の各地には古い岩盤があり、新しい通路が開いて昔からあった空間につながることもあります。
- 地上の人々と地下へ進んだ人々は、現在も交易や仕事を通じてつながっています。

**独立した「失われた超古代文明」の存在が確定しているわけではありません。** 以前の繁栄と現在の社会は、連続する歴史として捉える余地があります。

## 学者たちが議論していること
- なぜ豊かな地域と乏しい地域が入り組むのか。
- 新しい道を見つけたとき、岩盤自体は何年前からあるのか。
- ある鉱区の魔石が保存され、別の鉱区が劣化するのはなぜか。
- 迷宮の深部の生物は、どのようにその環境へ適応したのか。

学説は調査によって変化します。キャラクターが学者や測量士なら、こうした問いに興味を持っているかもしれません。

## 酒場で聞く噂（いずれも真偽未確定・冒険の種）
1. 「崩れた井戸の下に、誰も知らないもう一つの井戸がある」

3. 「地下湖には、近寄ると大きな物音を立てる生き物がいる」
4. 「市の古地図には、印刷されたものと手書きで直したものがある」
5. 「ある商会が、存在しないはずの駅の運賃表を買い集めている」
