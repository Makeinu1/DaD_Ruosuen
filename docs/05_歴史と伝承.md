# 歴史と伝承 — 誰もすべてを知ってはいない

この文書は**プレイヤーが作中で耳にする知識**です。確かな歴史、学者の仮説、酒場の噂は同じではありません。

## 広く認められている出来事

- この世界は**レウナ**と呼ばれ、地上ではかつて今より豊富なマナが生活・産業に使われていました。
- **約300年前に大転流が始まり**、およそ30年間に各地の地形と暮らしが変化しました。**約270年前の「大断裂」**はその時代を代表する大地震です。
- その後およそ100年間、資源の不足、旧国家の衰退・再編、地下への開拓が続きました。現在の五大国は、この歴史を経た世界で勢力を築いています。
- 迷宮の各地には古い岩盤があり、新しい通路が開いて昔からあった空間につながることもあります。
- 地上の人々と地下へ進んだ人々は、現在も交易や仕事を通じてつながっています。

**独立した「失われた超古代文明」の存在が確定しているわけではありません。** 以前の繁栄と現在の社会は、連続する歴史として捉える余地があります。

## 港町の建国と、失われた道の伝承

かつて王国の辺境だったルオスエンは、地下空洞への入口が開かれたことで繁栄し、長い権益争いの後、**約140年前に自由港協約**を結んで自治を確立しました。王国はその後滅び、ルオスエンだけがその歴史を受け継ぐ独立した都市として残っています。

協約の十年ほど前、空中港で魔導船が一斉に動きを止めたとされる**「停船の夜」**の物語が語り継がれています。黒い錨を持った帰還者の噂もありますが、何が実際に起きたのかは定かではありません。

また迷宮の最深部を聖地とする人々は、かつて「神を見た」と語った**最初の帰還者**の失われた道を探し、地下へ巡礼します。どこまでが歴史で、どこからが後世の解釈なのかは今も論争があります。

## 学者たちが議論していること
- なぜ豊かな地域と乏しい地域が入り組むのか。
- 新しい道を見つけたとき、岩盤自体は何年前からあるのか。
- ある鉱区の魔石が保存され、別の鉱区が劣化するのはなぜか。
- 迷宮の深部の生物は、どのようにその環境へ適応したのか。

学説は調査によって変化します。キャラクターが学者や測量士なら、こうした問いに興味を持っているかもしれません。
