# 短編セッションの進め方

## 基本的な遊び方
- **4人**の冒険者がパーティーを組みます。
- 一つの冒険は**1〜2回のセッションで完結**させます。
- 毎回、救助・測量・調査・討伐・採集など、明確な依頼があります。
- ダンジョンでは、戦闘だけでなく、観察、交渉、迂回、撤退も選択肢です。
- 依頼を達成して帰還できれば、その回の物語は決着します。すべての秘密を解く必要はありません。

## 遊ぶ時間（提案）
各回3〜4時間を想定しています。実際の所要時間、会場、オンラインツール、休憩頻度、開催日は参加者と決定します。

## 形式
単発として遊べる**短編連作**です。同じPCで連続参加すれば、以前出会った人や場所が次の冒険に顔を出すこともあります。毎回違う参加者・PCでの参加方法は別途検討します。

## 卓の安全と事前合意
キャラクター作成時に、避けたい描写や扱ってほしくないテーマ、事前連絡なく取り入れてほしくない要素があればDMに伝えてください。共有する範囲は本人が決められます。必要に応じてセッション中の中断・調整を認めます。

## セッション後
達成した依頼、見つけた場所、関係ができたNPC、プレイヤーの選択による変化は**参加者に共有できる範囲で**記録します。DM専用のシナリオ秘密や未発見情報は公開しません。
