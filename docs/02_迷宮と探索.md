# 迷宮と探索 — 道を知ることが、力になる

使い込まれた坑道の先に、まだ測られていない横道がある。新しく崩れた岩壁の向こうには、古くから続く空洞があるかもしれない。入口を見つけることと、その先を知ることは別だ。

## 地下にも、土地ごとの顔がある

迷宮は、古い地層や洞窟、断層、地下水脈、人が掘った坑道や施設が重なった世界だ。

狭い岩の裂け目を抜けると、遥か高い天井と大地を覆う光苔が、青白い星空のように輝く大空洞へ出ることがある。大断裂の爪痕が天井に残り、本物の陽光が降り注ぐ場所もある。空が見えても、そこから地上へ帰れるとは限らない。

地底湖、沈んだ遺構、未知の生き物。地下は一つの姿に収まらず、地上の常識では測れない世界が広がっている。

長く使われてきた道には、人や荷が行き交う。測量の拠点や倉庫が置かれ、採掘の仕事が続く場所もある。一方、崩落や湧水に注意が必要な地帯では、以前の記録だけを頼りに進むことはできない。

岩の質も、水の流れも、菌類や生き物の姿も、場所によって変わる。良質な魔石を探すなら、深さだけでなく、地層と保存環境を見極める知識が要る。

## そこに生きるものを知る

迷宮の魔物には、その土地で生きるための習性がある。何を食べ、何を恐れ、どこを縄張りとするのか。見つけた足跡や食べ残しが、武器を抜く前の手がかりになる。

強い生物が一帯を支配し、**領域主**と呼ばれることもある。その縄張りを通るのか、避けるのか。依頼によっては討伐が必要になるが、迂回や観察が目的を果たす道になることもある。

倒した後も、その土地には地形があり、生き物がいて、そこを使う人々がいる。

## 地図に描くのは、道だけではない

その橋は、荷を積んだ一行でも渡れるか。水を補給できるのはどこか。大きな物音を避けるべき場所はあるか。

迷宮の地図には、高低差や通路の幅、足場、湧水、換気、資源、生き物の縄張りといった情報が重ねられる。誰が管理する道か、どこまで通れるかという記録も、旅を左右する。

**帰り道まで確かめた地図は、次に向かう人の判断を支える。** 地図を作ること自体が仕事になり、見つけた通路が新しい交易の可能性を開くこともある。

発見の報酬や成果の扱いは契約によって異なる。出発前には、何を調べ、何を持ち帰る仕事なのかを確かめよう。

## 君たちは、どう進む？

- 生き物を観察し、戦わずに通れる時間や迂回路を探す。
- 見つけた標本を持ち帰るため、荷物と撤退路を考える。
- 現場の作業員や別の探索隊と、知っていることを交換する。
- 先へ進む危険と、今ある成果を持ち帰る価値を量る。

引き返すと決めることにも、経験と判断が要る。今日たどり着けなかった場所が、次の冒険の行き先になるかもしれない。
