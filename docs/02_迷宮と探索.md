# 迷宮と探索

## 迷宮とは
巨大迷宮は誰かが冒険者を試すために作った施設ではありません。長い地質史の中で形成された古い空洞、断層、地下河川、崩落地、採掘坑道、人工設備などが複雑につながった地下の世界です。

**最近見つかった通路が、最近作られた通路とは限りません。** 新しく崩れた岩壁の向こうに、何百万年も変わらず存在していた空洞が広がることもあります。

## 迷宮の場所ごとの違い
- **安定した古い通路：** 交通や採掘に使いやすいが、未踏の横道や古い閉鎖区画が残ることがある。
- **活動的な地帯：** 崩落、湧水、環境マナの変化などに注意が必要。
- **地下の自然環境：** 水、菌類、生物群集、鉱物が地域ごとに異なる。
- **人の活動する場所：** 測量拠点、倉庫、作業小屋、街道、市場、砦の遺構、違法採掘の現場など。

地形のすべてが毎日変化するわけではありません。安定して使われる道があるからこそ、人の街や運送業も成立します。

## 魔物と領域主
魔物は、迷宮の環境に適応して生きる生物です。すべてが悪意をもって人間を襲う存在ではありません。行動、食性、縄張り、恐れるものを調べることで、戦わずに切り抜けられることもあります。

大きな縄張りを持つ強力な生物は、ときに**領域主**と呼ばれます。領域主を倒すことが依頼の達成条件になる場合もありますが、常にそうではありません。討伐しても宝物が突然出現することはありません。

## なぜ地図が重要なのか
迷宮の地図は方向と距離だけではありません。
1. **地形と移動：** 高低差、通路幅、階段、橋、門、補給場所。
2. **地質と資源：** 地層、鉱物標本、推定鉱脈、採掘跡。
3. **危険と環境：** 崩落、湧水、換気、魔物の縄張り、観測されたマナの状態。
4. **人の権利と商い：** 誰が管理し、どこまで通れて、どれほどの荷が運べるか。

地図を描くこと自体が報酬になる依頼もあります。新しく発見した場所の権利や公開範囲は、個々の契約と都市・国家の制度によって扱いが異なります。

## プレイヤーが試せること
- 戦闘の前に敵の生活を観察し、弱点や迂回路を探す。
- 撤退路を確保し、重い荷物を持ち帰る手段を考える。
- 依頼された場所のほかにも、価値ある地形や資源を見つける。
- 他の探索隊や現場の人々と交渉する。

すべての冒険が「全部の部屋を通り、全部の敵を倒す」ゲームではありません。
