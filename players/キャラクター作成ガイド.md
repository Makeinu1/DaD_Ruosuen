# この世界で冒険する

迷宮のそばで育った人も、遠くからやって来た人もいる。まずは[ルオスエンを歩いて](../docs/04_自由迷宮都市と組織.md)気になった風景から、君自身の人物を考えてみよう。世界の歴史を全部知る必要はない。

## この街で、どんな日々を送っている？

まずは、次の三つを思い浮かべてみてください。すべてを決める必要はありません。

- **どこから来たのか。** ルオスエンで育ったのか、外の土地から辿り着いたのか。
- **何をして暮らし、誰を知っているのか。** 仕事、学びの場、馴染みの店や知人を一つ。
- **なぜ地下へ向かうのか。** 生活のため、知りたいこと、探しているもの。今、その人物を動かす理由を一つ。

## 気になった場所から、人物を考える

地図院へ測量の記録を届ける探検家。竜骨亭の職人に育てられた人物。伽藍の塔で学び、実地の調査に出る学生。聖路を探す巡礼者や、その旅を守る護衛。魔石工房へ原石を持ち込む山師。酒場で次の仕事を探す請負人。

こうした人物は、街とのつながり方の例です。組織への加入は必須ではありません。六つの場所のほかにも、川港や市場、宿屋などに居場所を考えられます。クラスや種族を選ぶ前に、どんな人として歩いてみたいか、想像してみましょう。

## こんな人物も、この街にいるかもしれない

以下は**発想のための例**。公式NPCでも、選ぶべき職業や種族でもない。別の職業や目的を組み合わせてもいい。

- **地図院で働く見習い。** 人の地図を写してきたが、いつか自分の発見を記録したい。
- **河港で働いていた護衛。** 地下の運搬隊に誘われ、初めて迷宮へ向かう。
- **竜骨亭の職人の子。** 地上を飛ぶ船を夢見て、珍しい魔石を探している。
- **地下の植物を扱う採集人。** 見たことのない生き物や薬材を見つけたい。
- **聖路を追う旅人。** 巡礼者を守る約束をしたが、伝承は信じ切っていない。
- **商館に出入りする請負人。** 大きな夢はない。仕事を終えて無事に帰りたい。

地図院の出身で今は船に乗っていてもいい。商館で働きながら教会の話に惹かれてもいい。**最初から迷宮の最深部を目指す必要はない。**

## 四人で、ひとつの冒険へ

ルオスエンを拠点に、救助・調査・探索などの仕事へ向かう短編の冒険です。一つの冒険は1〜2回のセッションで完結する形式を想定しています。戦うだけでなく、観察、交渉、迂回、撤退も選択肢。すべての秘密を解く必要はありません。

### 一緒に歩く理由

同じ仕事を引き受けた仲間。救助で結ばれた縁。一人が地図を持ち、別の一人が現地を知っている。最初から親友でなくても、共に動ける理由を一つ作りましょう。

他の三人と協力し、問題が起きたら話し合える人物を考えてください。避けたい描写やテーマはDMへ個別に伝えられます。遊んでいる途中でも、中断や調整を相談できます。

### 種族と、生きてきた暮らし

2024年版の基本種族は、ヒューマン、エルフ、ドワーフ、ハーフリング、ノーム、オーク、ゴライアス、ドラゴンボーン、ティーフリング、アアシマール。選択肢と採用範囲はDMと確認します。種族で職業や出身国は決まりません。この街で学ぶ人、働く人、旅する人として、人物像を考えられます。

## まずは暫定の作成条件

| 項目 | 作成時の目安 | 状態 |
|---|---|---|
| 使用ルール | D&D 2024年版（5e改訂版） | 暫定採用 |
| 開始レベル | **3レベル** | 提案・未確定 |
| プレイヤー人数 | 4人 | 希望確定 |
| 能力値 | 標準配列 `15, 14, 13, 12, 10, 8`（背景による修正は2024年版ルールに従う） | 提案・未確定 |
| クラス | 2024年版の基本クラスを原則候補とする | 要DM確認 |
| 種族 | 2024年版基本ルールを原則候補とする | 世界への当てはめは相談 |
| 装備 | クラスと背景の初期装備を基準とする | 追加品は未決 |
| サプリ・独自要素 | 使用前にDMへ相談 | 未決 |

**未確定の項目は、DMが決定する前にキャラクターを完成確定しなくて大丈夫です。** 先に職業や人物像を考えて構いません。

## 作り方

1. **どういう冒険者なのかを考える。** 迷宮に潜る理由を一つ決めます。金銭、知識、故郷の問題、救助の経験など何でも構いません。
2. **クラスを選ぶ。** 前衛、支援、探索、魔術など、やりたいプレイから決めてください。4人全員が完全に役割分担する必要はありません。
3. **背景と種族を選ぶ。** D&D 2024年版の背景・種族のルールを使います。世界固有の民族史や出身地はDMと相談できます。
4. **開始条件が決まったら、数値を整える。** 能力値・習熟・クラスの選択・呪文・装備は、合意した開始レベルと公式ルールに沿って準備します。
5. **パーティーとつながる理由を一つ作る。** 同じ依頼を引き受けた請負仲間、以前の救助の恩、共通の目標などで十分です。特定の商館やギルドへの加入は必須ではありません。
6. **考えた人物をDMに伝える。** 出身、暮らし、街とのつながり、迷宮へ向かう理由を数行で。未定のところは相談しながら考えられます。

## 必ず考えてほしい4つの問い

- なぜ危険な迷宮へ行くのか？
- 自分にとって魔石や魔導文明は何を意味するのか？
- 迷宮都市で、誰とどんなつながりがあるか？
- パーティーの仲間と協力できる理由は何か？

## 現時点で相談が必要なこと

- **蘇生魔法：** 世界の基本法則では死者の人格を元通りに呼び戻せません。蘇生呪文を扱うビルドはDMへ相談してください。
- **神との直接対話：** 神託や直接的な個人との会話を前提にする設定は調整が必要です。
- **世界の固有設定：** 国名、種族の文化、独自宗教、巨大組織の詳細は相談して一緒に決められます。
- **呪文の範囲：** テレポート・他次元移動・物質創造などが重要なキャラの場合は開始前に確認してください。今のところ包括的に使用禁止とは決定していません。

## 記入するもの

名前、出身、普段の仕事や暮らし、知り合い、地下へ向かう理由、仲間と協力できる理由を、決まったところからDMへ伝えてください。数値的なキャラクターシートはD&D Beyondや紙のシートでも構いません。**その人物がこの世界でどう生きてきたか**を、一緒に形にしていきましょう。
