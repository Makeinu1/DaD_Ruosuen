# キャラクター作成ガイド

最初に[世界の紹介](../docs/01_プレイヤー向け世界観.md)を読んでから始めてください。

## まずは暫定の作成条件

| 項目 | 作成時の目安 | 状態 |
|---|---|---|
| 使用ルール | D&D 2024年版（5e改訂版） | 暫定採用 |
| 開始レベル | **3レベル** | 提案・未確定 |
| プレイヤー人数 | 4人 | 希望確定 |
| 能力値 | 標準配列 `15, 14, 13, 12, 10, 8`（背景による修正は2024年版ルールに従う） | 提案・未確定 |
| クラス | 2024年版の基本クラスを原則候補とする | 要DM確認 |
| 種族 | 2024年版基本ルールを原則候補とする | 世界への当てはめは相談 |
| 装備 | クラスと背景の初期装備を基準とする | 追加品は未決 |
| サプリ・独自要素 | 使用前にDMへ相談 | 未決 |

**未確定の項目は、DMが決定する前にキャラクターを完成確定しなくて大丈夫です。** 先に職業や人物像を考えて構いません。

## 作り方

1. **どういう冒険者なのかを考える。** 迷宮に潜る理由を一つ決めます。金銭、知識、故郷の問題、救助の経験など何でも構いません。
2. **クラスを選ぶ。** 前衛、支援、探索、魔術など、やりたいプレイから決めてください。4人全員が完全に役割分担する必要はありません。
3. **背景と種族を選ぶ。** D&D 2024年版の背景・種族のルールを使います。世界固有の民族史や出身地はDMと相談できます。
4. **能力値・習熟・サブクラス・呪文・装備を記入する。** 開始3レベル案ではサブクラスを含めて準備します。詳細は公式ルールを参照。
5. **パーティーとつながる理由を一つ作る。** 同じギルドの契約仲間、以前の救助の恩、共通の目標などで十分です。
6. **下のテンプレートを埋めてDMに送る。** 詳細な小説を書く必要はありません。数行でも大丈夫です。

## 必ず考えてほしい4つの問い

- なぜ危険な迷宮へ行くのか？
- 自分にとって魔石や魔導文明は何を意味するのか？
- 迷宮都市で、誰とどんなつながりがあるか？
- パーティーの仲間と協力できる理由は何か？

## 現時点で相談が必要なこと

- **蘇生魔法：** 世界の基本法則では死者の人格を元通りに呼び戻せません。蘇生呪文を扱うビルドはDMへ相談してください。
- **神との直接対話：** 神託や直接的な個人との会話を前提にする設定は調整が必要です。
- **世界の固有設定：** 国名、種族の文化、独自宗教、巨大組織の詳細は相談して一緒に決められます。
- **呪文の範囲：** テレポート・他次元移動・物質創造などが重要なキャラの場合は開始前に確認してください。今のところ包括的に使用禁止とは決定していません。

## 記入するもの

[キャラクター提出テンプレート](キャラクター提出テンプレート.md)をコピーしてください。数値的なキャラクターシートはD&D Beyondや紙のシートでも構いません。テンプレートには**その人物がこの世界でどのように暮らしてきたか**を中心に記入します。
