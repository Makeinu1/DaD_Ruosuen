## 全ファイル共通の決まり

### 画面の座標の書き方
- 位置は画面の左上を (0%, 0%)、右下を (100%, 100%) とした割合で書く。「x40–60%」は横方向の範囲、「y20–50%」は縦方向の範囲。
- 大きさは「画面の高さに対する割合」で書く（例：人物の高さ30%）。
- 視点は目の高さ（m）、見下ろし・見上げの角度、レンズ相当（35mm判換算）で書く。

### 明暗の5段階
| 段階 | 意味 | 目安 |
|---|---|---|
| 1 | 最暗部 | ほぼ黒。描き込まない |
| 2 | 暗部 | 形だけ分かる |
| 3 | 中間 | 主な描写が入る |
| 4 | 明部 | 光が当たる面 |
| 5 | 最明部 | 光源そのもの。画面の5%以下 |

各ファイルの「明暗設計」はこの5段階の面積比。合計100%。

### 情報量の予算
- 主役は1つ。描き込む人物は3人まで。それ以上は形と灯りだけ。
- 画面の3割以上を「休ませる区画」（最暗部・霧・空・紙の白・平らな壁）にする。
- 奥ほど彩度・明暗差・細かさを落とす。手前と奥を同じ鮮明さで描かない。
- 光る結晶、舞う粒子、紋章、看板やラベルの文字、群衆は、ファイルに書かれた場合だけ入れる。
- 絵の中に文字・ロゴ・署名・地図の地名を入れない。

### 掲載方法の違い
- **冒頭9場面**：画面いっぱいに表示され、スクロールで前後の絵と重なりながら切り替わる。PCでは左側（x4–45%、y30–62%）に2行の見出しが白文字で重なる。スマホの縦画面では絵の中央の帯（x37–63%）しか見えない。
  → 主役は必ず x40–62% に置く。見出しの位置は暗く平らにする。
- **街歩き・世界史・冒険**：絵の全体が表示され、文章は絵の下か横に置かれる。文字の余白は不要。

## ChatGPT への渡し方

1. 新しい会話を始め、該当ファイルの「ChatGPTへの依頼文」をそのまま貼る。
2. ファイルに参照画像が書かれていれば、その画像を添付する。依頼文には参照の役割（画風だけ）がすでに書いてある。
3. 1回の依頼で1枚だけ生成させる。複数案を並べた1枚や、分割画にさせない。
4. 修正するときは、直したい点を1つだけ伝える。構図を変えたいときは、前の絵を編集させずに新しい会話で依頼し直す。
5. できた絵は、ファイルの「合格チェック」で確認してから送る。

## 納品と組み込み（作業者向け）
- 原寸の画像（PNG可）を受け取ったら、ファイルに書かれた保存名で `assets/` に WebP 化して置く。旧画は消さない。
- 公開原稿の画像参照を差し替え、`python3 scripts/build-responsive-art.py` を実行して、`assets/site.js` の `RESPONSIVE_ART` を manifest と一致させる。
- `node scripts/verify-public-sources.mjs` と `node tests/navigation.browser.cjs` を通す。
