# メモ帳 — アイデアの仮置き場

このディレクトリは、ルオスエンの**自由なメモ帳**です。会話中に出たアイデア、まだ整理していない疑問、採用前の案、思いつきの断片を置きます。

**ここに書いたことは、正式設定でもプレイヤー向け公開原稿でもありません。**

## 書き始める

- [アイデアメモ](アイデアメモ.md)：すぐ書ける雑記帳。
- 長くなった話題は、`notes/` に新しいMarkdownを作っても構いません。
- 思いつきをすぐ残す用途には、GitHubのIssueに「メモ」「アイデア」などのタイトルで投稿する方法もあります。

## メモから採用・公開まで

```text
notes/（自由なメモ、未承認）
      │  設定として採用する
      ▼
world/（世界設定の正本）
      │  プレイヤーに必要な情報だけを編集する
      ▼
docs/ / players/（公開原稿はここに1つだけ）
      │  GitHub PagesがMarkdownを直接読み込む
      ▼
Pages（表示専用。本文の二重管理をしない）
```

1. メモを**作者が採用した場合にのみ** `world/` の既存の設定ファイルへ反映します。
2. PC作成やセッション準備で必要な部分は `docs/`・`players/` の公開原稿へ反映します。
3. Pagesに載せる対象は `assets/site.js` の `SECTIONS` で管理します。**同じ本文のHTML版や別Markdown版を増やさない**。
4. 古いメモは採用された部分を示し、必要なら履歴として残せます。採用しなかった案も残せますが、現行設定と混同しません。

## 公開に関する重要な注意

このリポジトリは **Public** です。**`notes/` の中身もGitHub上では誰でも読めます**。Pagesのメニューに出さなくても非公開にはなりません。

未公開のシナリオの秘密、DMだけが知る真相、他の参加者の非公開PC設定、個人情報や秘密情報は、`notes/` にも書かず、アクセス制限された保管先を使ってください。

詳しくは [WORLD_POLICY.md](../WORLD_POLICY.md) を参照してください。
